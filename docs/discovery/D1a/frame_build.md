# D1a — 표본 프레임 구축 (모집단 `population.csv`)

> 계약 정본: [`docs/tasks/D1a.md`](../../tasks/D1a.md) `v1.2.1` §K-5 · K-7 · K-8 · K-9 · K-10 · K-11
> 검증: `python scripts/discovery/validate_d1a.py --check frame` · `--check population-quality`
> 집행 코드: [`frame_build.py`](./frame_build.py) · 기계 판독 산출: [`frame.json`](./frame.json)

이 문서는 **모집단이 어떻게 만들어졌는지**를 재현 가능한 형태로 기록한다.
값은 전부 `frame.json` 이 정본이며, 아래 기계 판독 블록은 그 정본과 검증기가 대조한다.

## 0. 재현 절차

```bash
# 1순위 — 자치구 단위 전수 파일 15종 (슬러그 5 × 자치구 3)
python3 docs/discovery/D1a/frame_build.py --download        <RAWDIR>
# 백업 — 서울 열린데이터광장 데이터셋 9종 (경로 교차검증용)
python3 docs/discovery/D1a/frame_build.py --download-backup <RAWDIR>
# K-10 보강 소스 — 심평원 분기 벌크 zip (프레임 소스가 아니다)
python3 docs/discovery/D1a/frame_build.py --download-enrich <RAWDIR>
# 빌드 — population.csv + frame.json (네트워크 미사용)
python3 docs/discovery/D1a/frame_build.py --build           <RAWDIR>
```

원본 인허가 파일과 심평원 zip 은 **리포지토리에 커밋하지 않는다.**
대신 `frame.json.datasets` 에 취득 URL · sha256 · 바이트 수 · 취득 시각이 남아 있고,
`download_log.json` 에 요청 단위 기록(요청 시각 · HTTP 상태 · 시도 회차)이 남아 있다.

## 1. 프레임 소스와 취득 경로 (K-5)

| 순위 | 호스트 | 단위 | 실측 |
|---|---|---|---|
| **1순위** | `file.localdata.go.kr` | 자치구 × 슬러그 = 15개 파일 | 전건 HTTP 200 |
| **백업** | `datafile.seoul.go.kr` | 데이터셋 9종 | 전건 HTTP 200 |

`frame_source` 는 전 행 `public_license_registry` 하나다.
`map_category_enumeration` 은 사용하지 않았다 (K-9 `map_enumeration_unused`).

**인허가 195종을 일원화하며 2026-04-16 정식 폐쇄된 구 포털 호스트는 사용하지 않는다.**
파일 서버(`file.localdata.go.kr`)는 **별개 호스트이며 살아 있다** — 둘을 혼동해
"LOCALDATA 는 죽었다"로 처리하면 1순위 경로를 통째로 잃는다.
검증기는 폐쇄된 포털 호스트 문자열이 문서·코드 전문에 0건인지 검사한다.

## 6. 좌표 변환 (K-8 · T-3)

원본 좌표는 **EPSG:5174** (Bessel 1841 중부원점 TM) 이며 WGS84 가 아니다.
변환 없이 위경도로 읽으면 좌표가 지구 반대편에 찍힌다.

| 파라미터 | 값 |
|---|---|
| 타원체 | Bessel 1841 — `a = 6377397.155`, `1/f = 299.1528128` |
| 원점 | `lat0 = 38.0°`, `lon0 = 127.0028902777778°` (= 127°00′10.405″E) |
| 축척·가산 | `k0 = 1.0`, `false easting = 200000`, `false northing = 500000` |
| 데이텀 변환 | Bessel → WGS84 7-parameter (position vector) `(-115.80, 474.99, 674.11, 1.16″, -2.31″, -1.63″, 6.43ppm)` |

**중부원점 경도를 127.0° 로 두면 안 된다.** K-10 대조 실측에서 중앙값 편차가 3.4m → 256.4m 로
뛴다. 10.405″(약 256m)는 무시할 수 있는 크기가 아니다.

### 6.1 변환 오차 실측 — K-10 독립 대조

`population.csv` 의 변환 좌표와 심평원 벌크 파일의 경위도(`좌표(X)`/`좌표(Y)`, 재투영 불필요)를
매칭 성립 행에서 대조했다. **좌표는 매칭 조건에 쓰지 않았으므로 순환논증이 아니다.**

**다만 K-9 `epsg5174_offset` 은 유지된다.** 위 실측은 (a) 매칭이 성립한 의료기관 행에 한정되고,
(b) 두 원천이 같은 주소 기반 좌표 부여 체계를 공유할 가능성을 배제하지 못하며,
(c) 최대값은 6,850.8m 로 개별 행에서는 킬로미터 단위로 어긋난다. 지도 핀 표시에는 충분하나
**"도보 N분"·최근접 정렬 같은 거리 연산의 근거로 쓰면 안 된다.**
