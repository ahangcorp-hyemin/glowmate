# O2 — 데이터 검수 어드민 (품질 큐)

> 개정 3판 (2차 감사 `docs/audit/round2-webops.md` O2 절 반영)
> 주요 변경: **`gate: G4` 제거**(존재 이유 역행 해소) · `review_audit_log`·정정값 저장 레이어 부재를 **선행 조건 표**로 승격 ·
> **수동 입력 레코드의 confidence 상한 0.69** 신설(재판정 입력 조작 경로 차단) · `category_axis` → `venue.category` ·
> D4 **rule_id 정본** 인용 · DB 접근을 F5 경유로 확정
> 추가(F2c 신설 반영): `ops.review_audit_log`·`ops.venue_field_override` 소유를 **F2c-OPS-LEGAL-SCHEMA** 로 이관 ·
> `force_public ⊂ hidden_quality` 경계를 REQ-5 에 명문화

    detect:       통합테스트(REQ-4 의 18케이스) — 사유코드 6종 각각에서 단독 승인이 403/409 로 거부됨을 assert

  - id: FORBID-2
    when:         검수 결과를 데이터에 반영하는 경우
    must_not:     venue.visibility·quality_score·reason_codes 직접 쓰기 또는 base 레코드 DELETE (F5 오버라이드 함수 경유만 허용)
    because:      두 번째 쓰기 경로가 생기면 다음 게이트 실행이 검수 결과를 덮어쓰거나 판정을 지워 공개 이유를 사후 재구성할 수 없고, G4 는 "미달 데이터는 비공개(삭제 아님)"이므로 물리 삭제는 다음 수집 주기에 같은 레코드를 되살린다
    detect:       CI 정적 검사(touches 내 판정 컬럼 UPDATE·DELETE 0건) + 통합테스트로 C7 재실행 후 오버라이드 결과 유지 assert
    on_violation: block_merge

  - id: FORBID-3
    when:         단일 actor 가 60분 내 20건을 초과해 공개 전환을 승인하려는 경우
    must_not:     추가 확인 절차 없이 승인을 계속 수락 (초과분은 429 와 함께 표본 감사 대기 상태로 전환)
    because:      "note 20자"는 상수 문자열 붙여넣기로 충족되므로 큐 120건을 30분에 전량 공개하는 것이 모범 준수가 된다. 그 순간 G4 는 통과 의례가 되고 지표는 품질이 아니라 승인 속도를 측정한다
    detect:       통합테스트 — 60분 창 21번째 승인이 429 이고 해당 레코드가 공개되지 않음을 assert
    on_violation: block_merge

  - id: FORBID-4
    when:         검수자가 스코어 입력값(가격 수치·소스 목록·수집일)을 정정하는 경우
    must_not:     source_url·entered_by 없이 저장하거나, confidence 를 0.69 초과로 지정하거나, C7 재판정 없이 동일 세션에서 그 레코드를 공개 승인
    because:      임계값을 건드리지 않고 입력을 손보면 게이트를 정면으로 통과시킬 수 있다. 검수자의 기억·추정으로 채운 값이 크롤링 근거와 구분되지 않으면 오류 1건의 출처조차 추적할 수 없고, confidence 를 높게 지정할 수 있으면 2인 승인 조건 자체가 소멸한다
    detect:       DB 제약 + 통합테스트 — source_url/entered_by 누락 422, confidence > 0.69 지정 시 422, 재판정 이벤트 없이 승인 시 409 assert

    when:         어드민 롤(reviewer, approver)이 ops.review_audit_log 에 접근하는 경우

    detect:       DB 권한 테스트(어드민 롤 UPDATE/DELETE 시 42501) + CI 정적 검사로 해당 테이블 대상 호출 0건
    on_violation: block_merge

    because:      사람 검수가 자동 검사를 대체한다고 가정하면 규제 문구가 그대로 공개되고, 의료광고법 위반은 해당 축 제외를 넘어 서비스 전체 중단으로 이어질 수 있다. 검사 시점을 수정 전으로 두면 수정→승인 2단계로 언제든 우회된다
    detect:       통합테스트 — (a) 금지표현 포함 medical 레코드 승인 시 422, (b) 정정으로 표현을 추가한 뒤 승인해도 422(최종 상태 기준), 검사 소스는 `packages/legal/medical/dist/exported_rules.json`(semver 핀)
