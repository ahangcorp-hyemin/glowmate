# D2 — SEO 키워드·SERP 난이도 실사

> **v2 — 1차 감사(REVISE) 반영.** 주요 변경: 난이도 임계 **하한을 계약이 고정**,
> 검색량 하한 신설, 대조군 20건(홀드아웃)으로 자기채점 차단, 엔진별 verdict 결합 규칙 명문화,
> SERP 원본 스냅샷 의무화, F1 `discovery` CI job 의존.

---

## 계약 고정 상수 — 조사자가 **선택할 수 없는** 값

> 감사 지적: "사후 완화는 막았으나 사전 설정이 무방비. 임계를 처음부터 느슨하게 잠그면
> 100% 준수로 G2가 거짓 통과한다." → 잠금 대상의 **허용 범위를 계약이 못박는다.**

### K-1. `enterable` 판정 하한 (이보다 **느슨하게** 정의할 수 없다)

키워드·엔진 조합이 `enterable` 이 되려면 1페이지 상위 10개 결과에 대해 **둘 다** 충족:

| 조건 | 하한 |
|---|---|
| 대형 플랫폼 제외 후 남는 **개별 서비스 도메인 수** | **≥ 3** |
| 그 중 **UGC**(개인 블로그·카페 글·커뮤니티 게시물) 비중 | **≥ 0.5** |

**"대형 플랫폼" 최소 제외 목록** (조사자는 추가만 가능, 제거 불가):
`blog.naver.com` · `cafe.naver.com` · `m.place.naver.com` · `kin.naver.com` · `post.naver.com` ·
`map.kakao.com` · `place.map.kakao.com` · `search.daum.net` · `google.com/maps` ·
`youtube.com` · `instagram.com` · `namu.wiki` · `ko.wikipedia.org` · `tistory.com` 도메인 루트

### K-2. SERP 실측 대상 자격

`google_volume + naver_volume ≥ 30` 인 키워드만 실측 대상이 된다.
그 중 검색량 합 상위 100개를 실측한다. 하한 미달 키워드는 `enterable` 집계의 **분자·분모 모두에서 제외**.

### K-3. 검색량 도구 (엔진별로 서로 달라야 한다)

| 엔진 | 허용 도구 enum |
|---|---|
| google | `google_keyword_planner` · `ahrefs` · `semrush` |
| naver | `naver_searchad_keywordtool` · `blackkiwi` |

### K-4. 상한·결합 규칙

| 항목 | 값 |
|---|---|
| G2 통과 기준 | 엔진별 `enterable ≥ 100` |
| `blocked` 신고 상한 | 엔진별 **≤ 20**. 초과 시 해당 엔진 `inconclusive` |
| **verdict 결합** | `naver_verdict != pass` → 최종 G2 = `channel_redesign` (구글 pass 여도) |
| | 양쪽 pass → `pass` · 어느 한쪽 inconclusive → `inconclusive` |
| 대조군 | `enterable` 대조군 10 + `hard` 대조군 10, 룰 확정 후 개봉 |
