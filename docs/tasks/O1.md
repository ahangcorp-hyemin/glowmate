# O1 — 게이트 지표 대시보드

> 개정 3판 — **2차 감사 REJECT 3사유 대응 재작성** (`docs/audit/round2-webops.md` O1 절)
> ① 임계 정본 파일이 계획에 없음 → **F1b 레지스트리 개정을 선행 조건 표로 승격**, 인용 형태로 재작성
> ② `gate: G4` 가 존재 이유와 역행 → **`[G1, G3]`** 으로 정정 (C7 과 동일)
> ③ 커버리지 분모를 C7(공개 업체)에 위임해 G1 이 구조적으로 통과 → **분모를 계약 본문에 수식으로 고정**
> 추가: H4·H6 카드 신설, `min_n`·집계 기간 허용 범위 못박기, 지표 쿼리 실행 경로를 F5 경유로 확정

## 선행 조건 — 상류 계약 개정 (미충족 시 착수 금지)

| # | 필요한 것 | 소유 계약 | 현재 상태 | 확인 방법 |
|---|---|---|---|---|
| 1 | 지표 레지스트리 `docs/registry/metrics.yaml` — 지표 ID 별 (threshold, bands, min_n, n_unit, window_days, 정의 수식) 6필드 | F1b-CONTRACT-GOVERNANCE (`docs/registry/**` 소유) | **부재** — 현 `ids.yaml` 은 3필드(id·정의·출처) | 파일 존재 + 스키마 검증 통과 |
| 2 | 신규 지표 ID 3종(`KM-parse-success`·`KM-override-public-ratio`·`KM-report-cohort-lift`)의 출처 등재 — F1 out_of_scope("PRD·Lean Canvas 에 없는 지표 창설 금지")와의 관계 정리 | F1b-CONTRACT-GOVERNANCE + PRD | 미해소 | `ids.yaml` 에 3종 등재 및 출처가 PRD 개정본 섹션을 가리킴 |
| 3 | PRD 임계 스냅샷 파일(FORBID-1 의 대조 대상) | F1b-CONTRACT-GOVERNANCE | 부재 | 레지스트리에 `source_snapshot` 해시 필드 존재 |
| 4 | 지표 SQL 을 실행하는 읽기 전용 함수 `runMetricQuery(name)` (F5 경계 준수) | F5-API-LAYER | 부재 | `packages/api` export 존재 |
| 5 | 커버리지 **분모** — C7 판정 대상 canonical venue 전체(visibility 무관)를 축별로 세는 쿼리 | C7-QUALITY-GATE REQ-8 확장 | C7 은 **공개 venue** 를 분모로 사용 | `report:g4-coverage` 출력에 `denominator_all_axis` 필드 존재 |

    on_violation: block_merge
