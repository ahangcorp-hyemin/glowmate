# 트렌드 포착 시스템 기획서 — 미용 시술·제품 트렌드 상시 관리

> 2026-08. 3갈래 종합(소스맵 / 탐지 방법론·툴 / 크롤·법·파이프라인).
> 목적: 우리가 관리하는 분야(시술·관련 제품)의 트렌드를 선행 포착해 콘텐츠(쇼츠·레슨)·제품 큐레이션·시술 카탈로그 갱신의 연료로.
> 스택: 기존 Supabase/Next M2 크롤 레이어 위에 얹음. 자매: `PRODUCTION_SPEC.md`(크롤 §5).

## 1. 설계 원리 — 2단 파이프라인

트렌드 전파 순서: **식약처/FDA 허가 → 장비사 IR → 강남 피부과 도입 → 시술앱·병원SNS → 유튜브 의사·커뮤니티 후기 → 검색량(데이터랩) → 올리브영 랭킹 → 다이소(끝물)**.

- **1단 "부상 포착"(선행 소스, 매일)**: 식약처 허가·장비사 IR·병원SNS·시술앱 → "뭔가 뜬다" 조기 신호. crawl 쉬움.
- **2단 "대중화·포화 검증"(후행 소스)**: 네이버 데이터랩(4050 연령필터)·올리브영 랭킹 → "실제 대중화 임계점" 정량 확인. **다이소 등장 = 하락 전환 알람.**

## 3. 무엇이 "트렌드"인가 — 신호 정의·탐지

**수집 데이터 → 구조화(LLM 추출)**: `{신흥키워드, 시술명, 성분, 제품, 감성(±), 불만유형, 근거스니펫, 소스, 날짜}`. LLM은 분류·요약·라벨만, 랭킹은 결정론 수식(재현성·비용).

**탐지 알고리즘 (표준 조합)**:
1. **velocity/acceleration** — 언급·검색량 1·2차 미분. *volume(현재)이 아니라 velocity(방향)가 조기신호*(Spate 원리).
2. **Kleinberg 버스트 탐지** — 단어 빈도 상태전이로 "지금 막 뜨는" 구간·강도 추출(`pybursts`).
3. **STL + MAD 이상탐지** — 계절성(가을 재생·겨울 리프팅·여름 무통) 제거 후 잔차. **스파이크(1회성)는 버리고 레벨시프트(지속상승)만 트렌드.**
4. **신조어·novel n-gram** — 사전에 없던 신규 시술·성분·브랜드명 최초 등장 감지.
5. **임베딩 클러스터링(UMAP+HDBSCAN+LLM 라벨)** — 신흥 토픽 발견 + 시간축 성장률 추적.

**복합 스코어** = w1·velocity + w2·burst + w3·클러스터성장 + w4·소스교차수.

**검증 게이트 (false positive 방지 — 핵심)**:
- **≥2개 소스 동시 상승**(검색+소셜+커머스 중) — 단일 소스 스파이크는 캠페인·봇 노이즈
- **3연속 주간 지속성** + STL 잔차 레벨 유지 → 스파이크 배제
- MAD>Z-score(베이스라인 오염 감소), precision 편향 튜닝

## 4. 파이프라인 (Supabase/Next 스택)

```
[pg_cron] ──▶ [Edge Function: fetcher] ──▶ [pgmq 큐]
  선행=매일/후행=주간          공식 API 호출·HTML 파싱        │
                                                            ▼
[외부 워커(Railway/Fly): 무거운 SPA 크롤·임베딩·클러스터]
                                                            ▼
   [정규화·중복제거(해시)] ──▶ raw_mentions(단기 TTL, 집계 후 파기)
                                     │
                                     ▼  velocity/burst/STL/클러스터
                              trend_daily(영구 집계) ──▶ 대시보드 + 주간 LLM 브리핑 + Slack 알림
```
- **스케줄**: pg_cron(선행 매일·후행 주간). **수집**: Edge Function(가벼운 API), 무거운 크롤·임베딩은 외부 워커 분리. **큐**: pgmq 재시도. **rate-limit**: 소스별 1~3s 간격·명시 UA(`GlowMateBot/1.0 +연락처`)·allowlist·동시성 제한. **차단 우회(CAPTCHA·프록시 로테이션) 지양**(여기어때 무죄 근거 = 우회가 아닌 공개접근).

- **설계 5원칙**: ① 원문 저장·재게시 금지(수집 즉시 집계 변환, 원문 파기/링크만) ② 전체 미러링 금지·증분만 ③ 개인정보(닉네임·연락처) 미저장 ④ 로그인벽 우회 금지·robots 존중 ⑤ 올리브영·화해는 크롤 대신 **제휴**.

## 6. Build vs Buy — 하이브리드

- **코어 self-build(우리 IP·해자)**: 네이버 데이터랩+쇼핑인사이트 API(무료) + 식약처 + 유튜브 + 경량 커뮤니티 → velocity/burst/STL/임베딩 랭킹 + LLM 추출. **여기서 트렌드 지표 80% 확보, 월 $0~20.**
- **감성·연관어 보강 구독**: **썸트렌드**(DATA+ Social API) — 국내 뷰티 감성·연관어 커버리지 즉시 확보.
- **분기 전략 리서치**: **리스닝마인드**(검색 인텐트·"가기 전" 질문 발굴) 필요 시.
- **글로벌 벤치**: **Spate**(뷰티 velocity 조기포착)는 참고. WGSN($15k~50k+)은 조기신호 약해 비추.
- ⚠️ pytrends 금지(2025.4 아카이브·429) → 공식 Trends API(alpha)/Glimpse. Glowing.AI·Trealytics는 실체 미확인.

## 7. 트렌드 → 제품 연결 (Actionability)

포착된 트렌드는 액션 큐로:
1. **콘텐츠**: 신흥 시술·성분 → 쇼츠·레슨 우선순위(예: "쥬베룩이 뜬다" → 레슨/『피부 속으로』 편 제작). velocity 상위 = 검색 신뢰자산 선점 기회.
2. **제품 큐레이션**: 올리브영·성분 트렌드(PDRN 695%↑ 등) → 발견 피드 제품·어필리에이트 갱신.
3. **시술 카탈로그 갱신**: 신장비 식약처 허가 → `procedures` 카탈로그에 신규 시술 후보 등록(자문의 감수).
4. **불만·공포담 감지**: 커뮤니티 감성 급락(예: "○○ 볼꺼짐") → contra 카드·후기 리터러시 콘텐츠 즉시 대응(C4).
5. **하락 알람**: 다이소 등장·velocity 음전 → 해당 콘텐츠·큐레이션 하향.

## 8. 착수 순서

- **P0(1~2주)**: 네이버 데이터랩·식약처·유튜브 API 연동 + 뷰티/시술 시드 키워드 100개 + velocity·STL 랭킹 → 주간 트렌드 브리핑 자동화. **여기까지가 80% 가치.**
- **P1**: 장비사 IR·커뮤니티(검색API 경유) 추가 + Kleinberg 버스트 + 임베딩 클러스터로 신흥 토픽 자동 발견.
- **P2**: 썸트렌드 감성 보강 구독 + 병원SNS·시술앱(크롤 검증 후) + 다이소 역지표 + 대시보드 UI.
- **주의(미검증)**: 네이버 API 일일 쿼터(데이터랩 통상 1,000콜/일·검색 25,000콜/일로 인용되나 공식 재확인), 올리브영·화해·커뮤니티 robots/약관은 수집 직전 재확인.
