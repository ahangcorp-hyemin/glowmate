# 글로우메이트 디자인 원칙 (v3 — 토스 컴포넌트 시스템 이식)

토스(TDS)의 시스템을 그대로 쓰되 내용과 키컬러(그린)만 우리 것. 아래 원칙에 어긋나는 UI는 리뷰에서 반려한다.

## 1. 색 — "회색으로 말하고, 그린은 행동에만"
- 바탕은 **순백**(#FFFFFF). 구획이 필요하면 **회색 면**(#F9FAFB, #F2F4F6)으로만 나눈다.
- 텍스트 위계는 그레이스케일로: ink `#191F28` → `#4E5968` → `#6B7684` → `#8B95A1` → `#B0B8C1`.
- **그린(#12A15A)은 오직**: 주 버튼, 핵심 숫자(가격·거리), 선택 상태, 파트너 배지. 그 외 전부 회색.
- 섹션 라벨(kick)도 회색이다. 컬러 라벨 금지.
- 경고·성공 등 시맨틱 컬러 외에 장식용 컬러 금지. 그라데이션 금지.

## 2. 타이포 — "위계는 굵기와 크기가 만든다"
- Pretendard 단일 서체. 세리프·모노 금지(가격 숫자만 예외 허용).
- 페이지 타이틀 24/800, 섹션 타이틀 20/800, 리스트 타이틀 16~17/700, 본문 15/500, 보조 13~14/500, 캡션 12/500.
- 자간 -0.02~-0.03em. 행간 제목 1.3 / 본문 1.55.
- 강조는 굵기(700↑)로. 색으로 강조하지 않는다(그린 예외 규칙 참조).

## 3. 면과 구획 — "보더와 그림자를 지운다"
- 카드/섹션 = **회색 면**(#F9FAFB) 라디우스 20. 보더 없음, 그림자 없음.
- 그림자는 떠 있는 것(지도 위 카드, 바텀시트)에만.
- 리스트는 카드 반복이 아니라 **행(row)**: 아이콘(40px 틴트 사각, r12) + 제목/보조 + 우측 값/셰브런. 행 사이 보더 대신 여백 또는 섹션 분리.
- 페이지 좌우 패딩 24px(모바일 22px 허용). 섹션 간 32px.

## 4. 컴포넌트 규격
- **주 버튼**: 그린 필, 라디우스 14, 높이 54~56, 16/700. 화면당 1개, 하단 고정.
- **보조 버튼**: #F2F4F6 필 + ink 텍스트. 보더 금지.
- **칩**: #F2F4F6 필 pill. 선택 시 그린 틴트(#E8F7EF) + 그린 텍스트. 보더 금지.
- **입력**: #F2F4F6 필, 라디우스 14, 포커스 시 그린 1.5px 링.
- **배지**: 회색 틴트. 파트너만 그린 틴트.
- **탭바**: 활성 = ink+굵게, 비활성 = #B0B8C1. 탭바에 컬러 쓰지 않는다.

## 5. 밀도 — "빈 화면을 만들지 않는다"
- 접힌 상태라도 다음 행동(추천 리스트, 최근 본 것)을 채운다.
- 일러스트는 상태 전환(완료·엠티)에만 소형으로.

## 6. 모션
- 페이드+8px 슬라이드 0.2s만. 장식 모션 금지.
