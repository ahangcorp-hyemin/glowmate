# G3 — 크롤링 소스 법적·기술적 실사 (게이트 상태 정본)

> 이 파일이 **G3 판정의 정본**이다. 이슈·PR 설명과 어긋나면 이 파일이 우선한다.
> 증거 정본: [`docs/discovery/D3/`](../discovery/D3/) · 보고서 [`report.md`](../discovery/D3/report.md)

## 1. 판정: `blocked_escalated`

- **어댑터 대상 소스: `official_website` 1개** (front-matter `adapter_targets` 가 정본)
- K-6 하한(`verdict ∈ {allowed, conditional}` 2개 이상)에 **미달**
- 따라서 `report.md` 에 `data_acquisition_blocked` 를 기록하고 대안 소스 5건의 실사 결과를 첨부했으며,
  **팀 리드 에스컬레이션(E-1)** 이 필요하다.

`adapter_targets` 는 `verdicts.csv` 의 `verdict ∈ {allowed, conditional}` 집합과 **정확히 일치**해야 하며,
`scripts/discovery/validate_d3.py --check report` 가 이를 강제한다.

## 2. 하류 태스크에 대한 효력

| 태스크 | 효력 |
|---|---|
| **C1-CRAWLER-CORE** | 착수 가능. 단 allowlist 는 [`crawl_policy.yaml`](../discovery/D3/crawl_policy.yaml) 의 `official_website` 항목을 **그대로 전사**하며, `allowed_path_globs` 를 임의로 넓히지 않는다 |
| **C2-ADAPTER-NAVER** | **착수 불가.** `naver_place` = `forbidden` (robots `Disallow: /` + ToS 자동수집 금지) |
| **C3-ADAPTER-KAKAO** | **착수 불가.** `kakao_map` = `forbidden` (robots `Disallow: /`) |

C2·C3 브랜치는 draft 로 유지한다. 제휴·공식 API 계약(E-3)이 성립하면 계약을 다시 쓰고
G3 를 재판정한다 — **본 파일을 고치지 않은 채 어댑터를 만들지 않는다.**

## 3. 준수 파라미터 (C1 전사 대상)

| 소스 | max_requests_per_min | max_concurrency | retry_backoff_sec | raw_retention_days | expiry_action |
|---|---|---|---|---|---|
| `official_website` | 6 | 1 | 30 | 90 | `tombstone_payload` |

`user_agent` · `allowed_path_globs` 는 [`crawl_policy.yaml`](../discovery/D3/crawl_policy.yaml) 정본.
`expiry_action` 은 K-4 고정값이며, F2 `source_record` 가 UPDATE·DELETE 를 DB 레벨에서 거부하므로
행 삭제 기반 만료를 도입하면 두 계약이 정면 충돌한다.

## 4. 재판정 조건

아래 중 하나가 성립하면 이 파일을 갱신하고 `status` 를 다시 매긴다.

1. `daangn` 이용약관 원문 확보 → `conditional` 승격 시 `adapter_targets` 2개로 K-6 충족 (E-2)
2. `naver_place`·`kakao_map` 공식 API 제휴 성립 (E-3)
3. `visitkorea` 약관 확보 + 강남3구 웰니스 상세 10건 도달 실증 (E-6)

## 5. 검증

```bash
python3 scripts/discovery/validate_d3.py --all
```

F1 의 CI job `discovery` 가 이 검증기를 실행한다.
`--check report` 는 이 파일의 front-matter 4필드(`gate`·`status`·`decided_at`·`source_pr`)와
`adapter_targets` ↔ `verdicts.csv` 일치를 검사한다.
