## 0. 핵심 요약 (Executive Summary)

**여정 한 줄**: 갱년기 급노화 충격("확 늙었다", 49~51세 집중) 또는 사회적 데드라인(자녀 결혼·동창회) → 지인 없으면 커뮤니티에 "해보신 분?" 질문 → 이 단계에서 **공포담에 선노출**(울쎄라 볼꺼짐 "얼굴에 지진", 안티울쎄라 카페 존재) → **"양심적 병원" 필터**로 선별 → 2~3곳 상담(같은 고민에 500~800만 견적 편차, 업셀 경험 → 불신 강화) → **"티 안 나게" 절대 조건** + 예산 100~200만으로 결정.

**가장 값진 발견 3개**
1. **"안 권하는 의사"가 최고의 추천 사유** — "비타민 주사 안 놔줘도 된다고 한 의사"가 커뮤니티 추천 1순위. 신뢰 단위가 후기 수량이 아니라 **사람**이라는 직접 증거.
2. **공장형을 고른 이유 1위가 "가격이 공개돼 있어서"** — 4050이 싼 걸 원하는 게 아니라 **투명한 걸** 원한다. 적정가 밴드 방향의 강한 근거.
3. **고가 시술 검토자는 공포담을 이미 본 상태로 진입** — 공포를 반박하지 말고 "내 조건(지방량·얼굴형)이면 해당되나"를 **판별**해주는 정보가 신뢰를 만든다. 울쎄라 레슨의 contra 카드가 정확히 이 지점.

**퀸잇 등식 번역**: 백화점 브랜드 = "전문의(akd.or.kr 기계 검증 → MVP 필터 즉시 구현) + 원장 직접 시술 + 업셀 없음 + 전화 예약". **"4050 전문" 표방 병원은 시장에 없음** = 공급 큐레이션 공백이자 선점 기회.

**프로토타입 결정**: 현 상태(견적 플로우+울쎄라 레슨+병원 비교)로 **동결하고 인터뷰 진행**. 전반 30분은 프로토타입 없이 과거 행동만(Mom Test), 후반 10분만 프로토타입 반응. "강남언니 써보셨어요?"는 먼저 꺼내지 않고 자발 언급 여부를 관찰(H-갭 핵심 시그널). 커밋 시그널 = 연락처 제공률.

## 1. 4050 의사결정 여정 (커뮤니티 증거로 재구성)

```
트리거 ──→ 탐색 ──→ 선별 ──→ 상담(2~3곳) ──→ 결정 ──→ 조용한 환원
```

1. **트리거**: 갱년기 급노화 충격(49~51세 집중, "확 늙었다·거울 보다 놀란다") + 사회적 이벤트가 데드라인 부여(자녀 결혼·동창회·복직). 성장 중: 딸이 엄마를 모시고 오는 '효도시술'(엄마는 "이 나이에 뭘" 자기검열).
2. **탐색**: 지인 후기가 없으면 익명 커뮤니티에 "해보신 분?" 직접 질문이 1차 채널. 시술명은 알지만 원리·차이는 모름. 이 단계에서 **공포 콘텐츠에 대량 노출**(울쎄라 볼꺼짐 "얼굴에 지진", 레이저 노화촉진설, 시술 의존 공포).
3. **선별**: 공장형(가격 투명·저렴) vs 동네 전문의(신뢰) 프레임. 최상위 필터 = **"양심적" 평판** — "안 권하는 의사"가 최고의 추천 사유.
4. **상담**: 2~3곳 순회하며 견적 편차(같은 고민에 500~800만원 제각각)·업셀링을 겪고 불신 강화, 또는 "강요 안 한 곳"으로 결정.
5. **결정**: 예산 상한(대개 100~200만) + "티 안 나게" 절대 조건. 울쎄라 공포 때문에 텐써마·슈링크 등 대체 선택 흔함.
6. **사후**: 2030처럼 앱 후기 문화가 아니라 커뮤니티 상세 후기 환원 + 조용한 지인 추천.

### 반복 패턴 TOP 10 (빈도순)
① 갱년기 "확 늙음" 충격 ② 상술·과잉진료 불신 → "양심적 병원" 탐색 ③ "티 안 나게" 절대 조건(설문 73.2% "한 듯 안 한 듯") ④ 울쎄라 볼꺼짐 공포담의 지배력(안티울쎄라 카페까지) ⑤ 커뮤니티 직접 질문 = 핵심 정보채널 ⑥ 가격 불투명·견적 편차 분노 ⑦ "기계보다 의사 손" 합의 ⑧ 시술 의존/중단 공포 ⑨ "타고난 살성" 회의론(효과 개인차→돈 아까움) ⑩ 딸 매개 유입 + 엄마의 자기검열

### 4050 실제 어휘 (카피에 그대로 쓸 것)
"확 늙었다" · "훅 갔다" · "티 안 나게" · "자연스럽게" · "곱게 늙자" · "관리" · "탄력" · "볼꺼짐" · "상술" · "양심적인 병원" · "과잉진료" · "공장형" · "거울 보는 게 무서워요"
(회피: "동안 되세요", 비포애프터 극대화, 이벤트/특가 언어)

## 2. 2030 vs 4050 결정 모델 대조

| 차원 | 2030 | 4050 |
|---|---|---|
| 트리거 | 유행·SNS·이벤트 특가 | 노화 자각 + 자녀·지인, 사회적 이벤트 데드라인 |
| 탐색 | 앱 후기 대량 비교, "10군데 발품·네고팁"(성예사 표준) | 소수 심층: 커뮤니티 질문·네이버 검색·단골 의료진 |
| 신뢰 단위 | 후기 **수량**·평점(강남언니 150만 후기 소구) | **사람** — "내 피부 아는 의료진"·지인 실물 결과 |
| 가격 태도 | 최저가 헌팅·가격 네고 | 적정가+바가지 회피. 단, 공장형 선택 이유 1위가 "가격 공개" → **투명성≠저가** [강도는 인터뷰 확인] |
| 목표 | 변화·쉐이핑 | 유지·복원·티 안 나게(73.2%) |
| 위험 태도 | 다운타임 감수, 후기로 학습 | 공포담 선노출 상태로 진입, 개인 편차·회복 민감 |
| 상담 수 | 5~10곳+, 이벤트 마감에 맞춘 속결 | 2~3곳 심층, 장기 계획형 |
| 사후 | 앱 후기·내돈내산 인증 | 커뮤니티 환원 + 조용한 지인 추천 |

**기존 앱과 충돌하는 것 5**: 이벤트/특가 피드 홈 · 후기 수백 장 그리드 · 최저가 정렬 · 익명 커뮤니티 줄임말 톤 · 다발 상담 유도.
**4050이 요구하는 것 5**: 증상 기반 탐색(처짐/꺼짐/색소) · 적정가+바가지 판별 · 의사 '사람' 정보 심층화(경력·상담 스타일·내 연령대 환자 비중) · 부작용/회복 상단 배치 · 상담 1~2회를 잘 쓰게 하는 질문 도구. → **현 프로토타입(증상 견적·적정가 밴드·질문지·레슨)이 이 5개와 정렬됨.**

## 3. 퀸잇 등식의 병원 번역 — "무엇을 입점시킬 것인가"

퀸잇의 백화점 브랜드 = 병원판 **"검증된 자격 + 원장 연속성 + 비영업 상담"**.

### 입점 큐레이션 체크리스트
- [ ] 피부과/성형외과 **전문의** (의사회 DB akd.or.kr로 **기계 검증 가능 → MVP 필터 즉시 구현**)
- [ ] **원장 직접 상담·시술** 명시 (페이닥터 로테이션 아님, 의료진 페이지=실제 시술자)
- [ ] 개원 연차·원장 재직 연속성
- [ ] **정품·샷수 공개 정책** (정품 팁 인증, 시술 후 실샷수 확인)
- [ ] 상담 견적 = 최종 결제 (업셀 없음) [미스터리 쇼핑으로 검증]
- [ ] **전화 예약 가능** (똑닥 50대 가입 3.65% — 앱 강제는 진입장벽)
- [ ] 리프팅·안티에이징 임상 중심 구성
- [ ] 프라이빗 대기·또래 상담인력 [인터뷰 확인]
- ⚠ TV 출연은 신뢰 신호로 쓰지 말 것(쇼닥터 불신 확립)

핵심: 강남언니류 랭킹 로직(이벤트·상위노출 광고)은 구조적으로 "이벤트 돌리는 병원"을 선별 — 4050 결정 변수가 하나도 반영 안 됨. **"4050 전문" 표방 병원은 시장에 없음 = 공급 큐레이션 공백이자 선점 기회.**

## 4. 커뮤니티 증거 → 인터뷰 검증 가설 (C1~C5)

*(검증 로드맵 H1~H5와 별개 번호. H1 인터뷰의 세부 가설로 흡수)*

- **C1**: 최대 병목은 가격이 아니라 '병원을 못 믿겠다'는 선별 불안 — 중립 정보만 정리해줘도 상담 전환 발생.
- **C2**: "티 안 나게"가 시술 선택을 지배 — 비포애프터 극대화 프레임은 이탈 유발.
- **C3**: 상담 2~3곳 순회가 표준 — 견적 비교·해석 도구 미충족 니즈 큼.
- **C4**: 고가 시술 검토자는 공포담 선노출 상태 — 공포 반박이 아닌 '내 조건별(지방량·얼굴형) 판별' 정보가 신뢰를 만듦.
- **C5**: 딸은 트리거, 결정권은 본인 — "이 나이에 돈 쓰기 미안함" 죄책감 해소가 결정을 앞당김.

## 5. H1 인터뷰 가이드 초안 (Mom Test — 과거 행동만)

**대상**: 최근 2년 내 리프팅·시술을 받았거나 진지하게 알아본 45~58세 여성 15~20명.
**구조**: 전반 30분 과거 행동(프로토타입 없이) → 후반 10분 프로토타입 반응.

전반 질문(순서대로):
1. "얼굴 관리를 진지하게 알아보게 된 계기가 있었나요? 그때 상황을 들려주세요." (→트리거 검증)
2. "그때 제일 먼저 뭘 하셨어요? 그다음엔요?" (→탐색 채널, 앱 사용 여부는 먼저 묻지 말고 나오는지 관찰 — H-갭 핵심)
3. "병원은 몇 군데나 가보셨어요? 각각 어떻게 고르셨어요?" (→C3, 선별 기준)
4. "상담에서 기억나는 좋았던/불쾌했던 순간은요?" (→업셀·불신 경험, C1)
5. "결정을 미루거나 포기한 적 있다면 왜였나요?" (→공포담·의존 공포·죄책감, C4·C5)
6. "받고 나서 주변에 이야기하셨어요? 누구한테, 어떻게?" (→사후 행동, K-factor 전제)
7. (앱 언급이 나왔다면) "강남언니 같은 앱은 써보셨어요? 어땠어요?" (→H-갭 직접 검증. 먼저 꺼내지 말 것)

커밋 시그널 체크: 인터뷰 말미 "다음 버전 나오면 보여드릴까요? 연락처 남겨주시겠어요?" — 연락처 제공률을 기록(칭찬은 데이터 아님).

## 6. 제품·카피 즉시 반영 가능 항목

1. 레슨 콘텐츠에 **볼꺼짐 공포 정면 대응 카드** 추가 여지 — "울쎄라 볼꺼짐, 나는 해당될까?"(마른 얼굴·지방량 조건별) = C4 대응. 현 contra 카드가 이미 일부 커버.
2. 랜딩 카피를 4050 실어휘로: "확 늙은 것 같은 날" / "티 안 나게, 자연스럽게" / "상술 걱정 없이 알고 가세요". (§56 필터 통과 확인 필수)
3. 견적 결과에 "이 가격대면 적정 범위예요/확인이 필요해요" 바가지 판별 신호 — 견적 편차 분노(⑥) 대응.
4. 병원 카드에 전문의 검증 배지(akd.or.kr 대조) — 큐레이션 1번 항목 선반영.
5. "이 나이에 뭘" 죄책감 해소 톤 — "관리는 사치가 아니라 안목" 계열 메시지(C5).

## 7. 인터뷰 리크루팅 실행 계획

### 7.1 누구를 (스크리닝 기준, n=15~20)

| 세그먼트 | 인원 | 기준 | 왜 |
|---|---|---|---|
| **경험자** | 8~10명 | 최근 2년 내 리프팅·피부시술(울쎄라/써마지/실/슈링크/보톡스 등) 실제 시술 | 여정 전체(탐색→상담→결정→사후) 복원 |
| **검토 후 보류자** | 5~7명 | 상담·견적까지 갔으나 결정 안 함/미룸 | **포기 이유가 금맥** — C1(선별 불안)·C4(공포담)·C5(죄책감) 직접 검증 |
| **딸 매개** | 2~3명 | 자녀 권유·동반으로 병원 방문 경험 | C5 + 효도시술 유입 루프 검증 |

- 공통: 45~58세 여성, 서울·수도권(강남/분당 접근 가능 — 초기 타깃 지역과 일치), 본인 의사결정권 보유.
- 스크리닝: 구글폼 5문항(연령대/최근 2년 시술·상담 경험/받은·알아본 시술명/거주 지역/인터뷰 가능 시간) + 응답자 전원 소액 기프티콘. 폼 응답으로 세그먼트 배정 후 개별 연락.
- 제외: 의료·뷰티 업계 종사자와 그 가족, 팀의 직접 지인(지인의 지인부터 OK).

### 7.2 어디서·어떻게 모집 (채널 우선순위)

1. **지인의 지인 스노우볼 (1차, 목표 6~8명)** — 3인 팀의 부모·이모·회사 선배망에 "소개해줄 만한 분" 요청. 직접 지인은 제외(Mom Test — 예의상 칭찬 오염). 인터뷰 말미 "비슷한 고민 하는 친구분 소개해주실 수 있어요?" 스노우볼 연장 — 4050의 '조용한 지인 추천' 경로를 그대로 리크루팅에 활용.
2. **지역 맘카페·주부 카페 (2차, 목표 4~6명)** — 강남·서초·분당·판교 지역 카페. **운영진에 사전 허가 필수**(무단 홍보글은 즉삭+신뢰 손상). "병원·판매 아님, 스타트업 인터뷰 협조" 프레임. 이 세그먼트는 상술 경계가 높으므로 실명·회사명·목적·보상·개인정보 미수집 명시가 전환의 핵심.
3. **당근 동네생활 (2차 병행)** — 강남·분당 동네 인증 계정으로 게시. 지역 기반이라 대면 인터뷰 전환이 쉬움.
4. **네이버 밴드 4050 모임 (3차)** — 등산·독서·지역 밴드. 퀸잇이 실증한 4050 도달 채널. 운영자 협조 후 게시.
5. **유료 패널 (부족분 보충)** — 오픈서베이 등 조사 패널로 잔여 인원 충원(비용 ↑, 발화 진정성 ↓ — 최후 수단).
- ❌ 인스타/페북 광고 리크루팅: 4050 도달 비효율(퀸잇 교훈) + 리서치엔 과한 CAC.

### 7.4 형식·장소·운영

- **대면 우선**: 참가자 동네의 조용한 카페(찾아간다). 4050은 줌 대비 대면에서 발화량·신뢰가 훨씬 높고 화상 셋업 자체가 장벽. 전화는 차선, 줌은 최후.
- **2인 체제**: 진행 1(질문만) + 기록 1(발화 그대로 메모). 녹음은 시작 시 구두+서면 동의, 거부 시 메모만.
- **시간**: 45~60분. 사례비 5만원(신세계·백화점 상품권 선호 — 커피 기프티콘보다 4050 수용성 높음).
- **동의·데이터**: 시술 이력은 민감정보에 준함 — 1장짜리 동의서(목적: 서비스 기획 리서치 / 보관: 익명화 후 내부만 / 파기: 6개월). 이름 대신 코드(P01…)로 기록.
- **일정**: 주 5~7명 × 3주 = 15~20명. 매주 금요일 팀 합동 디브리핑으로 C1~C5 지지/반박 태깅 → 10명 시점에 중간 판정(패턴 수렴 시 조기 종료 가능).

### 7.5 성공 판정 (H1 연결)

- **Pass**: "기존 앱 미사용 또는 불신" + "선별 불안(C1)" 시그널이 인터뷰의 60%+에서 자발적으로 등장.
- **Kill**: "강남언니로 충분했다"가 다수 — 이 경우 4050-first 포지셔닝 재고, 특가·이벤트 시장임을 인정.
- 부차 지표: 연락처 제공률(커밋), 지인 소개 전환율(스노우볼 = K-factor 프록시), 프로토타입 반응 중 "이거 언제 나와요?" 자발 질문 수.
