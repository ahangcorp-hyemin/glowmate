# AX in 우리 영업 여정 (2인 팀 생존 레버리지)

2인 팀이 이 판에서 죽지 않으려면 = **볼륨에 묶인 일은 AI로 10배, 신뢰에 묶인 일은 사람 2명에 집중.** 실리콘밸리 2026 GTM 논의의 합의도 정확히 이거다: "기술 이해도 있는 소수 GTM 팀 + AI 대량 증강, 사람 판단은 최고 레버리지 결정에만."

## 리서치가 준 3개의 냉정한 진실 (이걸 어기면 돈·시간 날림)
1. **자율 AI SDR(사람 빼고 AI만)은 업계 전반에서 기대 이하.** → "AI가 영업 다 해준다" 환상 금지. ([ZoomInfo](https://pipeline.zoominfo.com/sales/ai-sdr-for-outbound-sales), [Amplemarket](https://www.amplemarket.com/blog/best-ai-sales-agents))
2. **성공의 80~90%는 데이터 배관·라우팅·가드레일, 프롬프트는 10~20%.** → 레버리지는 clever 프롬프트가 아니라 **깨끗한 데이터 + 워크플로우.** ([digitalapplied 바이어 가이드](https://www.digitalapplied.com/blog/ai-sdr-agents-2026-buyers-guide-landscape-pricing))
3. **사람 판단은 최고 레버리지 결정에만.** 5인 팀이 20인 몫 커버하는 구조. ([ICONIQ GTM 리포트](https://www.iconiq.com/growth/reports/gtm-org-structure-ai-2026), [Taskade](https://www.taskade.com/blog/ai-agents-startups))

## 우리 영업 여정 단계별 AX 매핑
(여정: 수요생성 → 리드포착 → 대행 → 리드밀도 → 전환제안 → 온보딩 → 유지)

| 단계 | AX 개입 | 레버리지 | 사람이 지킬 것 |
|---|---|---|---|
| **1. 수요 생성**(콘텐츠·SEO) | AI가 지역×시술 프로그래매틱 SEO·레슨·Q&A·후기리터러시 **초안 대량 생성** → 사람 편집 + §56 게이트 | ★★★ (최고) | 톤·사실검증·§56 최종판단 |
| **2. 리드 포착** | 이미 자동(visit_requests). AI가 **"어느 병원 3건↑ 넘었다" 알림** | ★★ | — |
| **3. 대행 콜 준비/기록** | AI가 리드별 **콜 스크립트 생성** + 통화 후 요약·상태 로깅 | ★★ | 실제 전화(한국 병원 관계) |
| **4. 리드 밀도 추적** | AI 에이전트가 병원별 누적·전환 파이프라인 **대시보드 + "지금 제안할 병원" 추천** | ★★★ | 우선순위 최종 판단 |
| **5. 전환 제안 아웃리치** | AI가 병원별 **개인화 피치 초안**(리드수·프로필 근거) 채널별(문자/카톡/이메일) 작성·시퀀스 | ★★ | **발송·관계·클로징은 사람** (자율 금지) |
| **6. 온보딩** | AI가 파트너 프로필 초안(HIRA+웹 리서치)·계약 안내 자동화 | ★ | 계약·신뢰 |
| **7. 유지** | AI가 파트너 월간 리드 리포트 자동 생성·발송 | ★★ | 관계 관리 |

## 병원 dossier 자동 리서치 (전환 아웃리치의 데이터 배관 = 80% 게임)
전환 제안 전, 비치헤드 병원마다 AI가 공개정보를 긁어 **타깃 자료** 구축:
- HIRA 기본(있음) + 웹 리서치(원장명·강점·기존 마케팅·리뷰 존재감·인스타 등)
- 이게 개인화 피치의 재료. Clay/Apollo류 or 우리 커스텀 스크립트. 도구보다 **파이프라인 설계**가 핵심.

## 절대 AI에 넘기지 말 것
- 병원 원장과의 **실제 신뢰 통화·클로징** (한국 의료 B2B는 전화 관계가 모트)
- **§56 최종 컴플라이언스 판단** (유저 대면 문구)
- 밀도/전환 **우선순위 최종 결정**

## 2인 팀 실행 순서 (레버리지×실현성)
1. **수요 엔진 AI화** — 프로그래매틱 SEO·콘텐츠 초안 대량화(파이프라인 이미 있음, check-s56 게이트). 2명이 100명 콘텐츠 아웃풋.
2. **"지금 제안할 병원" 에이전트** — visit_requests 집계 + 3건↑ 추천. 데이터 이미 있음, 싸다.
3. **병원 dossier 자동 리서치** — 아웃리치 데이터 배관.
4. **아웃리치 초안 + 시퀀스** — 사람이 발송.
5. **방문신청 시 병원 자동 문자**(반자동 대행) — SMS 연동 필요.

## 메타 포인트
우리는 **제품 빌드 자체를 이미 AI로 레버리지**하고 있다(이 세션이 그 증거). 같은 방식을 영업 여정에 이식하면, 2명이 볼륨 일을 10배로 밀고 신뢰 일에만 붙는다. 그게 유일한 생존 경로.
