# 글로우메이트 스케일업 로드맵 (컨시어지 → 파트너 전환 모델)

## 전제: 컨시어지는 제품이 아니라 영업이다
미입점 병원 방문 대행(수동 전화)은 Zocdoc의 초기(문 두드리며 직접 영업 + 캘린더 손동기화)와 동일한 "do things that don't scale"이다. 강남언니(리뷰로 수요 선점)·모두닥("6년 삽질")도 초기엔 갈아 넣었다. 정상이다.

**핵심 재정의**: 컨시어지 전화 = 병원이 "글로우메이트가 리드를 준다"를 체험하는 첫 세일즈 터치. 스케일업은 전화를 늘려서가 아니라 **병원을 파트너로 전환**시켜 병원당 수작업을 0으로 수렴시키는 것.

## §27이 만드는 유닛 이코노믹스 제약
- 건당 수수료 불가 → 컨시어지 노동은 **광고 전환으로만 회수되는 영업비용(CAC)**.
- 생존 부등식: **(전환된 파트너의 광고 LTV) > (전환까지 든 컨시어지 CAC)**.
- 따라서 컨시어지는 **전환 파이프라인 병원에만, 기간 제한**해서 투입. 무한 무료 대행 금지.

## 두 개의 엔진
1. **수요 엔진(모트)**: 콘텐츠·SEO·후기(실결제 가격)·자동견적 → 4050 오디언스. 강남언니/모두닥 둘 다 수요 먼저.
2. **공급 엔진(수익)**: 컨시어지 → 리드 증명 → 파트너 전환 → 셀프서브 → 월정액 광고.

## 단계별 로드맵

### Phase 0 — 수동 컨시어지 + 수요 시딩 (지금)
- **하는 일**: 방문신청 수동 대행 전화, 리드 이벤트 전량 기록, 후기(실결제) 수집, 4050 콘텐츠/SEO.
- **증명 대상**: (a) 4050이 이 결정정보+예약도움을 실제로 원한다 (b) 병원별 리드 카운트 축적.
- **졸업 기준**: 꾸준한 방문신청 인바운드 + 리드 3건↑ 쌓인 병원 다수(전환 탄약).
- **수작업**: 100% 수동 전화. 예상된 것. (Zocdoc도 수개월~수년)

### Phase 1 — 리드 증명 → 첫 파트너 전환
- **하는 일**: 병원 대상 **"이번 달 N명 보냈어요" 리포트** 생성(visit_requests 기반). 리드 상위 병원부터 콜드아웃리치: "저희가 방문희망 N건 보냈어요. 파트너 되시면 바로 받고, 프로필 채우고, 우선 노출돼요(월정액)."
- **증명 대상**: 병원이 리드+오디언스에 **돈을 낸다(정액)**. LTV > CAC 성립.
- **졸업 기준**: 첫 유료 파트너 N곳, 전환율 측정 가능.
- **수작업**: 컨시어지 계속(타깃팅) + BD는 창업자 수동.
- **필요 개발**: 어드민에 병원별 리드 집계 뷰 + 리포트 export(문자/PDF).

### Phase 2 — 파트너 셀프서브 → 컨시어지 축소
- **하는 일**: 파트너 대시보드(방문신청 직수신·프로필 관리·자기 리드 열람). 파트너 예약은 **문자/카톡 자동 전달**(글로우메이트 전화 불필요). 컨시어지는 전환 시도 중인 미입점만.
- **증명 대상**: 건당 수작업 하락, 파트너 셀프서브.
- **졸업 기준**: 예약 다수가 파트너 셀프서브, 컨시어지 <X%(파이프라인 병원 한정).
- **필요 개발**: 병원용 인증/대시보드, 예약 자동 전달(SMS 연동), is_partner 라우팅 강화.

### Phase 3 — 양 엔진 스케일
- **하는 일**: 수요는 콘텐츠/SEO/후기로 규모화(모트), 공급은 인바운드(4050 오디언스 보고 병원이 먼저 옴)+경량 BD. 미입점 아웃리치 반자동화(방문신청 시 병원에 자동 문자 선발송, 무응답만 전화).
- **증명 대상**: CAC↓, 유기적 공급 인바운드, 광고 매출 복리.
- **필요 개발**: 방문신청→병원 자동 SMS(HIRA 전화 데이터 보유), 리드 트래킹 계측.

### Phase 4 — 수익화 심화
- 정액 광고 티어, 후기 기반 검증 가격, 프로필 강화, 카테고리 확장. 전부 §27 준수(건당 수수료 없음).

## 추적 지표 (어드민이 결국 보여줘야 할 것)
- 병원별 이번 달 리드 수(visit_requests)
- 리드당 컨시어지 시간(수작업 비용)
- 파트너 전환율
- 파트너 MRR / LTV
- **생존 지표: 컨시어지 CAC vs 파트너 LTV 비율**

## 지금 코드에서 Phase 1로 가는 최단거리
- `visit_requests`에 병원별 리드가 이미 쌓임 + `is_partner` 플래그 존재 → **어드민에 "병원별 리드 집계 + 이번 달 N건" 뷰만 붙이면** 세일즈 리포트가 나온다. 이게 다음 개발 1순위 후보.
