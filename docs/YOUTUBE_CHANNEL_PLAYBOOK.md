# 자체 유튜브(쇼츠) 채널 플레이북 — 레퍼런스·포맷·운영

> 2026-08. 2갈래 병렬(쇼츠 포맷 벤치마크 / 스타트업 자체 채널 성과·운영). 결론:
> **"시술 가격 팩트체크 + 호구방지" 시리즈 채널은 경쟁 공백 × 4050 적합 × 3인 제작 가능의 교집합.**
> 단, 쇼츠 단독으로 설치를 만드는 건 장기 베팅 — 목적은 '검색 신뢰자산', 설치는 크리에이터 제휴 병행.

---

## 1. 왜 쇼츠인가 (데이터)

- **쇼츠 최다 시청층 = 40대(23.2%, 와이즈앱)**. 60대 숏폼 이용률 54.3%. "쇼츠=젊은층" 통념은 틀림.
- 4050은 완주율이 높고(20분 롱폼도 50%+ 완주) 광고단가도 높은 시청층.
- 단, 구독·로그인 개념 약함 → 검색·알고리즘에 반복 노출되는 **시리즈 규격**이 필수.

## 3. 포맷 판정 (4050 적합 × 3인 제작)

- **주력**: ① 1분 해설(자료화면+큰 자막) ② **가격 폭로·비교**(자체 데이터 독점) — 둘 다 ◎/◎
- **시그니처**: 팩트체크·저격 페르소나(구독 복리) + 리액션(훅 비용 0)
- **보류**: 스킷(연기력·젊은층 편향), 인터뷰 발췌(섭외 비용, 2단계)
- **버림**: faceless 사연·캐릭터 쇼츠(뷰만 쌓이고 전환 0 — AI 사연 쇼츠는 이미 포화·불신), ASMR/비포애프터(§56·심의 리스크)

## 4. 콘텐츠 필러 + 쇼츠 아이디어

훅 문법 = **증상공감("~할 때") + 숫자 + 손실회피**. 모든 카피는 4050 실어휘(리서치 §1) 사용.

**P1. 진짜 가격 시리즈** (독점 데이터·차별화 무기)
- "울쎄라 300샷, 진짜 가격은요"
- "써마지 99만원 광고의 비밀 (소형 팁이에요)"
- "같은 얼굴인데 견적이 500만 vs 180만인 이유"
- "보톡스 국산 vs 수입, 가격 차이의 진실"

**P2. 호구 방지 시리즈** (저격 페르소나)
- "상담실장이 이 말 하면 일단 나오세요"
- "당일 결제 압박, 이렇게 대응하세요"
- "정품 팁 확인하는 법, 30초면 돼요"
- "피부과에서 호구 되는 과정 3단계"

**P3. 1분 비교 시리즈** (검색 수요 직결 — "명확한 설명이 없다"는 유저 호소 실측)
- "울쎄라 vs 써마지, 나는 뭐가 맞아요?"
- "실리프팅이 나은 사람, 울쎄라가 나은 사람"
- "울쎄라 무서우면 텐써마? 차이 1분 정리"

**P4. 팩트체크 리액션** (훅 비용 0 · §56 주의: 병원 식별정보 모자이크)
- "이 시술 광고, 걸러야 할까요?" (바이럴 광고 판정)
- "'10년 어려진다'는 후기, 의사는 뭐라 할까"

**P5. 상담 질문지 시리즈** (캡처·공유 유도 = 앱 자산과 직결)
- "울쎄라 상담 때 이 6개만 물어보세요" (화면 캡처 유도)
- "병원 갈 때 딸이 챙겨주는 질문 리스트" (딸 프레임)

## 5. 운영 체계 (3인 팀 현실판)

- **케이던스**: 주 3~5개. 배치 제작(반나절에 대본 8~10개) + 템플릿 고정 + Vrew(TTS·자동자막·컷편집). 1인 주 1일 이내 공수로 제한.
- **소재 재사용**: 레슨 카드 콘텐츠(이미 §56 필터 통과한 카피)를 쇼츠 대본으로 변환 — 제작 한계비용 최소화. 견적 엔진 데이터 = P1 소재 자동 공급.
- **외주 옵션**: 쇼츠 편집 건당 2만~13만 (주 5개 외주 시 월 40~60만).
- **기간 기대치(정직)**: 의미 있는 트래픽까지 최소 3~6개월·영상 50~100개. **성과 판단은 80개 전 유보.**

## 6. 쇼츠→앱 퍼널

링크 클릭 전환 1% 미만 — 링크는 약함. 실전 장치 우선순위:
1. **고정댓글에 정보 미끼**: "우리 동네 울쎄라 시세 전체보기 →" (구독 요청보다 구체 CTA. 고정댓글 경유 구독자는 활성화 2~3배)
2. 쇼츠→관련 롱폼 링크 → 롱폼 설명란에 앱 딥링크 (2단계 퍼널)
3. 프로필 링크 + 구두 CTA ("프로필에서 견적 확인")

## 7. §56 가드레일 (기획 단계 체크리스트)

복지부 의료광고 위반 적발의 85.7%가 비의료인 광고 — 우리(비의료기관)도 대상.
- ❌ 치료경험담·전후사진·효과 보증("이거 받고 10년 어려짐")
- ❌ 특정 병원명·연락처·가격 안내로 내원 유도 (유인·알선 시 징역 3년/벌금 3천만)
- ❌ 병원에게 대가 받고 만드는 콘텐츠(협찬 표기해도 위반 소지)
- ⭕ 시술 원리·평균 가격대·부작용·체크리스트 등 **일반 의학정보**(특정 기관 비연계) + 부작용 등 중요 정보 누락 금지
- ⭕ 의사 출연 시 소속병원 홍보 배제(강남언니 방식)

## 8. 정직한 기대치와 병행 전략

- **경고 사례**: 강남언니 강언TV — 전담 ~10명, 2년, 누적 4,950만뷰에도 **구독 10만에서 정체**, 획득 채널 증거 없음. 바비톡·여신티켓도 자체 채널로 획득 못 만듦. 토스 머니그라피(50만)·오늘의집(76만)은 전담 조직+3~4년의 결과물.
- **그래서 목적 설정**: 자체 채널 = '설치 채널'이 아니라 **검색 신뢰자산**(시술명 검색 시 우리 콘텐츠가 뜨는 상태) + 브랜드 페르소나 구축. 설치는 **퀸잇 모델**(4050 시청층 보유 크리에이터 제휴 — 필미커플·뽀따TV, `4050_YOUTUBE_LANDSCAPE.md` 참조)을 병행.
- **소팀 반례 희망**: 자청(영상 20개로 16만→사업 유입), 약쿠르트(6개월 12만) — 공통점은 양산이 아니라 **"신뢰 가는 인물 + 소수 고밀도 + 상식 뒤집기"**. 우리도 볼륨보다 P1·P2의 밀도에 걸어야 함.
