## 2. 소스 3계층 (정직성·확보난이도 순)

- **A. 공식 공개데이터(HIRA)** — 무료·합법·출처명시 가능. 병원정보·진료과목·교통·진료시간·전문의수·시설.
  → **골격 + 신뢰 차별점.** (지금 우리가 쓰는 3개 API가 여기)
- **B. 지도 플랫폼(Kakao/Naver Place)** — 사진·영업시간·방문자평점·편의시설. 단 **REST는 제한적**(Kakao Local=카테고리·전화·place_url·좌표만; 사진/리뷰/영업시간은 지도 상세페이지에만). Naver Place 공식 API는 리뷰 미제공.
  → **링크아웃 + 카테고리/전화 보강.** (사진·리뷰까지는 크롤 gray 영역)
- **C. 제휴 / 자체 UGC** — 병원 소개·의료진 프로필·이벤트가(§27 정액광고 제휴로 병원이 직접 제공), 후기(우리 '후기 리터러시' + 자체 실후기 축적).
  → **깊이이자 BM.** 시간이 필요하지만 강남언니의 진짜 해자.

## 3. 우리 차별화 (강남언니 클론 금지)

1. **모든 정보에 출처 뱃지** — "HIRA 공식 / 병원 제공 / 지도" 라벨. 강남언니엔 없는 **신뢰**.
2. **가짜 카운트·평점·"N명" 금지**(§56). 후기를 **로그인 게이트하지 않음**(강남언니는 게이트).
3. **'알고 가는' 결정정보(레슨)를 병원 상세와 연결** — 강남언니에 없는 우리 코어. "이 병원 가기 전 이 시술 알고가기".
4. **4050 톤**(큰 글씨·담백·딸 컨셉).

## 4. 권장 로드맵

- **Phase 1 (지금·공식데이터 최대화)**: HIRA 의료기관별상세 API의 요청 param을 활용가이드로 확정
  → 진료과목·전문의수·진료시간·교통(최근접역)·시설 뱃지. + 지도 임베드. 상세 컬럼 확장(0007).
  ⚠️ 현재 상세 오퍼레이션이 빈 응답 — ykiho 인코딩/버전/필수 param 재확인이 선결.
- **Phase 2 (지도 보강)**: Kakao REST 키 활성화(앱 플랫폼 등록) → place_url 링크아웃 + 좌표→최근접역·카테고리.
- **Phase 3 (제휴·UGC)**: §27 정액광고로 병원 소개·의료진·이벤트가 수집, 자체 후기 시스템(리터러시 연계).

## 5. 법 체크
- **§56**: 과장·평점조작·허위 카운트 금지. 공개데이터는 출처 명시로 안전.
- **§27**: 병원 링크아웃·무수수료, 광고는 정액만.
- **개인정보**: 의료진 실명은 공개정보 범위 내. 환자 후기 수집 시 동의.
- **크롤**: robots/allowlist/비중대성(여기어때 무죄 vs 잡코리아 유죄) — 사진·리뷰 크롤은 신중, 링크아웃 우선.
