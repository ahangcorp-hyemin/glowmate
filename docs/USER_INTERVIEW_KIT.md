# 유저 인터뷰 총괄 킷 — 구글폼 설계 + 답변별 액션아이템

> 2026-08-15. 방법론: [Mom Test 스크리너 규칙](https://www.userinterviews.com/ux-research-field-guide-chapter/screener-surveys)(과거 행동만·10문항 이하·목적/회사명 비노출·유도 금지) ×
> [Sean Ellis PMF 40%](https://review.firstround.com/how-superhuman-built-an-engine-to-find-product-market-fit/)(Superhuman 세그먼테이션 — 경쟁앱에 적용) ×
> [JTBD 4 Forces](https://jobstobedone.org/the-four-forces/)(Push·Pull·Anxiety·Habit — 포기/보류 = anxiety 측정).
> 기존 자산: 4050_DECISION_RESEARCH §5(H1 대면 가이드)·§7(리크루팅). 이 킷은 **커뮤니티 배포용 구글폼**과 **판정→액션 규칙**을 담당.

## 0. 이 폼의 역할 (대면 인터뷰와 분업)

```
구글폼(n=100~300, 정량) ──┬── 스크리너 → 대면 인터뷰 15~20명 선별(세그먼트 쿼터)
                          ├── 차별점 6개의 우선순위 정량 검증 (V1~V6)
                          └── H-갭(경쟁앱 불만족) · anxiety(포기 이유) 정량화
대면 인터뷰(n=15~20, 정성) ── 4 forces 심층 + 프로토타입 반응 (기존 §5 가이드)
```

Mom Test 원칙 적용: 폼 안에서 **우리 제품을 설명하지 않는다**(마지막 인터뷰 동의 전까지 서비스명 비노출). 모든 문항은 과거 행동 또는 강제선택. "~하면 쓰시겠어요?"류 미래 의향 문항 금지 — 유일한 예외인 Q10(차별점 선택)은 **보조 지표**로만 사용.

## 1. 검증할 차별점 가설 (경쟁사 대비)

| # | 우리 차별점 | 경쟁사 현재 | 폼 문항 |
|---|---|---|---|
| V1 | 근거·출처 있는 설명("왜 이 시술인지") | 이벤트·후기량 중심 | Q7, Q10 |
| V2 | 무수수료 중립("병원 편 아니라 내 편") | 광고 순위·전환 수수료 | Q8, Q10 |
| V3 | 4050 눈높이(큰 글씨·해요체·티 안 나게) | 2030 문법(줄임말·특가) | Q6, Q10 |
| V4 | '알고 가기'(레슨·질문지·사전 무장) | 없음 | Q5, Q10 |
| V5 | 병원 개입 차단 후기 | 대가성 후기 논란 | Q7, Q9, Q10 |
| V6 | 내 주변 실병원(공공데이터 전국) | 강남 중심 제휴병원 | Q4, Q10 |

## 2. 구글폼 문항 (배포용 · 소요 3분 · 12문항)

> 폼 제목: "피부·시술 알아본 경험 3분 설문 (사례비 추첨/인터뷰 별도 사례)"
> 인트로: "병원·판매와 무관한 서비스 기획 리서치입니다. 답변은 익명 통계로만 사용돼요."

### A. 스크리너 (Q1~Q3)
- **Q1.** 연령대를 골라주세요. `30대 이하 / 40~44 / 45~49 / 50~54 / 55~59 / 60대 이상`
  → 40~59 외는 §C로 점프(응답은 대조군으로 보관).
- **Q2.** 최근 2년 안에 피부·시술(리프팅, 보톡스, 레이저 등)과 관련해 해당되는 걸 모두 골라주세요. *(복수)*
  `실제 시술을 받았다 / 병원 상담·견적까지 받았다 / 알아봤지만 미뤘다·포기했다 / 가족(자녀 등)이 알아봐줬다 / 해당 없음`
  → '해당 없음' 단독이면 종료(감사 화면). **세그먼트 배정**: 경험자/보류자/딸매개.
- **Q3.** 본인 또는 가까운 가족이 의료·미용 업계에서 일하시나요? `예 / 아니요` → '예' 제외(통계만).

### B. 행동 회고 (Q4~Q9 · 과거 행동만)
- **Q4.** 가장 최근에 시술 정보를 알아볼 때, **실제로 했던 행동**을 모두 골라주세요. *(복수)*
  `네이버·구글 검색 / 유튜브 시청 / 지인에게 물어봄 / 맘카페·커뮤니티에 질문 or 검색 / 강남언니·바비톡 등 앱 설치 / 병원에 직접 전화 / 자녀·가족이 대신 알아봐줌 / 기타(주관식)`
- **Q5.** 병원 상담을 받아보셨다면, 상담 **전에** 가장 알고 싶었지만 못 찾았던 정보는 무엇이었나요? *(주관식 1줄, 선택)*
- **Q6.** 병원은 몇 군데나 알아보셨나요(상담·전화 포함)? `0 / 1 / 2~3 / 4곳 이상`
- **Q7.** 알아보는 과정에서 실제로 겪은 일을 모두 골라주세요. *(복수)*
  `같은 시술인데 병원마다 가격이 크게 달랐다 / 상담에서 계획에 없던 시술을 권유받았다 / 후기가 광고 같아 믿기 어려웠다 / 부작용 이야기를 보고 겁이 났다 / 용어·설명이 어려웠다 / 앱 글씨·화면이 불편했다 / 딱히 불편함 없었다`
- **Q8.** (Q2에서 '미뤘다·포기'를 고른 분) 결정을 미루거나 포기하신 **가장 큰 이유** 하나를 골라주세요.
  `어떤 병원을 믿어야 할지 몰라서 / 부작용이 무서워서 / 가격이 적정한지 알 수 없어서 / 티 날까 봐 / 이 나이에 돈 쓰기 미안해서 / 시간이 없어서 / 기타(주관식)`
- **Q9.** 강남언니·바비톡·모두닥 같은 앱을 써보셨다면 — 그 앱이 **내일 없어진다면** 어떤 기분일까요? *(Sean Ellis 변형 — 경쟁앱 PMF 측정)*
  `써본 적 없다 / 매우 아쉽다 / 조금 아쉽다 / 아쉽지 않다(그 이유: 주관식 선택)`

### C. 차별점 강제선택 (Q10 · 보조 지표)
- **Q10.** 만약 시술 정보를 알아본다면, 다음 중 **가장 도움이 될 것 같은 것 하나**만 골라주세요. *(순위 강제 — 미래 의향이므로 보조 지표)*
  `① 왜 이 시술이 나에게 맞는지 근거·출처를 보여주는 설명(V1) / ② 병원에서 광고비를 받지 않는 중립 추천(V2) / ③ 40·50대 눈높이의 쉬운 설명과 큰 글씨(V3) / ④ 병원 가기 전 뭘 물어볼지 알려주는 준비 가이드(V4) / ⑤ 광고·대가 없이 검증된 또래 후기(V5) / ⑥ 내 동네 병원을 거리순으로 공정하게 비교(V6)`

### D. 리크루팅 (Q11~Q12)
- **Q11.** 45~59세이고 위 경험이 있으시다면, 1시간 대면/전화 인터뷰(사례비 5만원)에 참여해주실 수 있나요? `참여 의사 있음 / 없음`
- **Q12.** (참여 의사 있음) 연락처와 편한 방법을 남겨주세요. *(연락처 수집·이용 동의 체크 필수, 인터뷰 조율 목적 한정·종료 후 파기)*

## 3. 답변 → 액션아이템 판정 규칙

| 문항 | 판정 규칙 (threshold) | 액션아이템 |
|---|---|---|
| Q4 | '커뮤니티 질문·검색' ≥ 40% | Q&A SEO(F6)·커뮤니티 어휘 콘텐츠 **증산** — 획득 채널 확정 |
| Q4 | '유튜브' ≥ 40% | 콘텐츠 유닛에 **영상 트랙 조기 착수**(모두닥 백두산 경로 재현) |
| Q4 | '자녀·가족 대신' ≥ 15% | **딸 보내기(F1) P0 승격**, 공유 카드 우선 구현 |
| Q4 | '앱 설치' ≤ 20% | H-갭 확정 — "앱 없는 시장" 포지셔닝 강화, 웹/검색 유입 집중 |
| Q5 | 주관식 클러스터링(가격/부작용/병원선택/시술차이) | 최다 클러스터를 **Q&A 1호 콘텐츠·레슨 카드**로 즉시 제작 |
| Q6 | '2~3곳' ≥ 50% | C3 확정 → **상담 D-day·견적 기록장(F3) P1 확정** |
| Q7 | '가격 편차' ≥ 50% | **적정가 신호(P0-4) 재개** + 가격 Q&A 우선 |
| Q7 | '후기가 광고 같다' ≥ 40% | V5 소구를 랜딩 첫 화면으로 승격, 후기 검증 배지 강조 |
| Q7 | '권유(업셀)' ≥ 30% | V2(무수수료 중립) 카피를 병원찾기 상단 고정 |
| Q7 | '글씨·화면 불편' ≥ 20% | V3 — **접근성 패스**(폰트 스케일·대비) 1스프린트 |
| Q8 | '병원 불신' 1위 | C1 확정 — 신뢰(출처·중립) 중심 온보딩 유지·강화 |
| Q8 | '부작용 공포' 1위 | C4 — 레슨 contra 카드 확장("나는 해당되나") + 회복 가이드(F4) 승격 |
| Q8 | '죄책감' ≥ 15% | C5 — "관리는 안목" 계열 카피 A/B, 딸 선물 프레임 강화 |
| Q9 | '써본 적 없다'+'아쉽지 않다' ≥ 60% | **H-갭 검증 통과** — 4050-first 포지셔닝 확정, 입점 영업 덱에 수치 인용 |
| Q9 | '매우 아쉽다' ≥ 40% | ⚠ 경쟁앱이 이미 PMF — 차별점을 '보완재'로 재정의(Kill 아님·피벗 신호) |
| Q10 | 1위 항목 | 해당 V를 랜딩 히어로 카피·앱스토어 한 줄 소개로 승격. 2·3위는 온보딩 3카드 순서 재배열 |
| Q11 | 전환율 < 5% | 사례비·채널 재검토(맘카페→당근 비중 조정), 폼 길이 축소 |
| 전체 | 세그먼트별(경험자/보류자/딸매개) 교차 | 보류자의 Q8·Q7이 **가설 스코어보드(HYPOTHESIS_VALIDATION)**의 C1~C5 지지/반박 업데이트 |

**분석 규칙**: Superhuman 방식 세그먼테이션 — Q10 응답을 Q2 세그먼트별로 갈라, '보류자'가 고른 차별점(=전환 장벽 해소책)을 '경험자'가 고른 것(=만족 강화책)보다 로드맵에서 우선한다.

## 4. 운영
- 배포: 기존 리크루팅 플랜(§7.2) 채널 그대로(맘카페 사전허가·당근·밴드). 폼 링크만 교체.
- 목표: 응답 100+(2주), 인터뷰 전환 15~20명(세그먼트 쿼터: 경험자 8~10·보류자 5~7·딸매개 2~3).
- 개인정보: 연락처는 Q12 동의자만, 조율 목적 한정, 인터뷰 종료 후 파기(§23 스크립트 기존 문서 재사용).
- 대면 인터뷰는 기존 §5 가이드(Mom Test·전반 30분 과거행동·후반 10분 프로토타입) 그대로.
