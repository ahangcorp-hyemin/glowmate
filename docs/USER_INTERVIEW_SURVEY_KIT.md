## 3. Computer-Use 에이전트 빌드 프롬프트 (그대로 전달)

```
당신은 Google Forms를 브라우저로 직접 만드는 에이전트입니다. 아래 스펙대로 폼 하나를 처음부터 끝까지 정확히 제작하세요. 창작·의역 금지 — 제목·질문·선택지 텍스트는 큰따옴표 안 내용을 글자 그대로 입력합니다.

[전제] 브라우저가 Google 계정에 로그인돼 있어야 합니다. 저장 버튼은 없고 자동 저장됩니다. 각 단계 후 화면을 확인하고 다음으로 진행하세요.

[중요한 Google Forms 동작 규칙 — 반드시 숙지]
1) 섹션 분기(답변 기반 이동)는 '객관식 라디오'와 '드롭다운'에서만 됩니다. '체크박스'는 분기 불가 → 분기가 필요한 질문은 절대 체크박스로 만들지 마세요.
2) 한 섹션에 분기 질문을 여러 개 두면 충돌합니다. 그래서 분기 스크리너(Q1·Q2·Q3)는 각각 별도 섹션에 하나씩만 둡니다(아래 구조대로).
3) 분기 대상 섹션은 먼저 존재해야 합니다. → 먼저 '섹션 8개 뼈대 + 각 질문'을 다 만들고, 맨 마지막에 분기 규칙을 한꺼번에 설정하세요.
4) '옵션 순서 섞기'는 질문 우측 하단 ⋮ 메뉴의 '옵션 순서 무작위로 섞기'입니다. 지정된 문항에만 켜세요.
5) 섹션 추가는 우측 툴바의 '섹션 추가(=)' 아이콘입니다. 섹션 이동 규칙과 '이 섹션 다음에' 드롭다운은 각 섹션 하단/질문 ⋮에서 설정합니다.

[제작 순서]
STEP 0. forms.new 로 새 빈 양식 열기.
STEP 1. 설정(톱니바퀴):
   - '응답' 탭: 이메일 주소 수집 = 수집 안 함. 응답 횟수 1회로 제한 = 끔(로그인 불필요). 응답 편집 = 끔.
   - '표시' 탭: 진행률 표시줄 표시 = 켬. 질문 순서 무작위 표시 = 끔.
   - 확인 메시지 = "소중한 답변 감사합니다 🙏 인터뷰 참여를 남겨주신 분께는 순차적으로 연락드릴게요. 모든 답변은 익명 통계로만 활용됩니다."
STEP 2. 제목/설명 입력(맨 위):
   - 제목: "피부·시술, 어떻게 알아보셨어요? (3~4분 · 익명)"
   - 설명: (아래 <폼설명> 블록 전체를 그대로 붙여넣기)
STEP 3. 섹션 8개 뼈대 만들기: '섹션 추가'를 7번 눌러 총 8개 섹션. 각 섹션 제목만 먼저 입력 —
   S1 "연령" / S2 "경험" / S3 "확인" / S4 "그때 어떻게 하셨어요" / S5 "인터뷰 참여" / S6 "연락처" / S7 "간단 참여" / S8 "감사합니다"
STEP 4. 각 섹션에 질문 채우기(아래 <문항> 순서·타입·필수·셔플 그대로). '기타' 표시가 있으면 '기타 추가'를 사용. 필수(*) 문항은 '필수' 토글 켜기. 셔플(⇄) 표시 문항은 ⋮ → '옵션 순서 무작위로 섞기' 켜기.
STEP 5. S6의 Q14는 체크박스에 선택지 "동의합니다" 하나만 두고 '필수' 켬. Q13은 단답형 필수.
STEP 6. S7에는 <문항>의 Q11 하나만 복제해 넣기(라디오·필수·셔플).
STEP 7. 분기·섹션이동 일괄 설정(<분기맵> 그대로):
   - Q1 ⋮ → '답변을 기반으로 섹션으로 이동' 켜고 각 선택지 대상 지정.
   - Q2, Q3, Q12 동일하게 선택지별 이동 지정.
   - S6, S7, S8 하단 '이 섹션 다음에' = '양식 제출하기'로 변경. Q12의 '아니요' 이동도 '양식 제출하기'.
STEP 8. 미리보기(눈 아이콘)로 3개 경로를 클릭 검증: (a) 47세·시술받음·업계아니오 → 본편 전체→인터뷰까지, (b) '특별히 알아본 적 없다' → 바로 감사(S8), (c) '60대 이상' → S7 또는 S8. 오류 있으면 수정.
STEP 9. 게시/링크: 우측 상단 '게시'(또는 '보내기')로 '링크가 있는 모든 사용자'가 응답 가능하도록 하고 공유 URL을 복사해 최종 출력에 제시. 테스트 응답은 실제 제출하지 마세요(미리보기만).
