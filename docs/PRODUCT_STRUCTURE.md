> 2026-08-15. 소스: 모두닥 조직도 노션 + 백두산팀(시니어 견적)·건빵팀(건강검진) 인터뷰 정독.
> 목적: "견적·병원찾기·콘텐츠·후기"를 각각 **지표와 오너가 있는 제품 유닛**으로 쪼갠다.

## 2. 유닛 정의 (오너 지표·현재 상태·다음 백로그)

### U1 견적 (매칭 엔진) — 전환
- **한 줄**: 고민만 말하면 시술 조합·비용·근거. 모두닥 백두산의 "견적 서비스" 포지션.
- **북극성**: 견적 완료율 → [이 시술 병원 보기] 전환율
- **현재**: ✅ 도메인 질문·룰엔진·캐러셀·레슨 연결 완료
- **다음**: 적정가 신호(P0-4 중단분) · 견적 결과 공유(F1 딸 보내기) · 견적 저장

### U2 병원 찾기 (디렉터리·탐색) — 전환
- **한 줄**: 실위치 기준 전국 전문의 병원 + 상세 + 문의 CTA. 광고 순위 없이 가까운 순.
- **북극성**: 병원 상세 진입 → CTA(전화·길찾기) 클릭
- **현재**: ✅ 전국 2,791곳·상세 탭·지도·공개 페이지+sitemap(#57~59)
- **다음**: 전문의 배지(15001699 전파 대기) · 시술별 필터 강화 · 후기 연결

### U3 알아보기 (콘텐츠) — 획득
- **한 줄**: '알고 가는' 레슨·Q&A·비교. SEO 오가닉 유입 = 모객 엔진이자 입점 영업 증거.
- **북극성**: 오가닉 세션 → 견적/병원으로의 내부 전환
- **현재**: ✅ 레슨 5종 + 생산 방법론(CONTENT_PLAN)
- **다음**: Q&A 페이지(F6) · 비교결정기(F2) · 레슨 배치3(필러·인모드·스킨부스터) · (후속) 유튜브 트랙

### U4 후기 (신뢰 자산) — 해자
- **한 줄**: 4050 검증후기 수집→피드. 모두닥이 '리뷰 플랫폼'으로 시작한 그 해자.
- **북극성**: 검증 후기 수(영수증 인증률)
- **현재**: 🌱 수집 모드 화면만. **P0-5 후기 폼이 최우선 미구현**
- **다음**: 후기 폼(+§23 동의·영수증 업로드) · 검증 큐(U7 연동) · 피드 전환

### U5 입점·파트너 (B-side 세일즈) — 매출 전제
- **한 줄**: 병원 모객 레이어. "4050이 모입니다" 증거(U3 지표) 들고 입점 제안.
- **북극성**: 입점 병원 수 (모두닥: 입점=선택지=액션율=매출)
- **현재**: ❌ 없음
- **다음**: 입점 랜딩+문의폼(P1-6) · 트래픽 리포트 자동 첨부 · 병원 셀프 프로필(의료진·사진·소개 — 공공 API 부재 확정이라 입점 가치제안의 핵심)

### U6 광고·과금 — 매출
- **한 줄**: §27 안전한 정액 노출 광고부터. 모두닥처럼 과금 모델은 병원 만족 기준으로 진화시키되, 성과형은 유인·알선 법리 검토 선행.
- **북극성**: 광고 갱신율(병원 만족의 대리 지표)
- **현재**: 스키마만(ad_placements 정액, 수수료 컬럼 없음)
- **다음**: 입점 3곳+ 후 노출 상품화 · 광고 라벨 UX(이미 원칙 있음)

### U7 어드민·운영 — 내부
- **한 줄**: 유저·병원·운영자 3자 관점의 운영 도구.
- **현재**: ❌ 없음 (§56 write-트리거가 DB단 방어만)
- **다음**: 후기 검증 큐 → 병원 데이터 정정 → §56 검수 대시보드 (입점·후기 볼륨 생기면)

### U8 시술수첩 (여정·리텐션) — P2
- H1 인터뷰에서 회복불안 강도 확인 후. (MVP_LAUNCH_PLAN §P2-1 유지)

### D0 데이터 플랫폼 (공통)
- HIRA 인제스트(전국 2,791·probe) · 카탈로그/룰/레슨 시드 · 컴플라이언스(bannedPhrases+트리거+check-s56) · Supabase 스키마 0001~0006

## 3. 우선순위 (모두닥 렌즈 재정렬)

모두닥 공식 = **버티컬 하나(리프팅)를 깊게 + 입점이 성장 변수 + 콘텐츠가 유입**.

1. **U4 후기 폼** (P0-5) — 해자의 씨앗. 미루면 데이터가 안 쌓임. ★최우선
2. **U3 Q&A·비교결정기** (P0-2·3) — SEO 유입 = 입점 영업 증거 만들기
3. **U1 적정가 신호 + 딸 보내기** (P0-4·6) — 전환·유입루프 마감
4. **U5 입점 랜딩** (P1-6) — U3 지표가 조금이라도 생기면 즉시
5. U2 전문의 배지(probe 뜨는 대로) · U7 후기 검증 큐(후기 쌓이면)

## 4. 조직 러닝 (3인 팀 적용)
- 모두닥 스쿼드처럼 **유닛별 오너 1명**(복수 겸임)을 정하고, 유닛 = 북극성 지표 1개로 관리.
- "필요한 문제에 다 같이 붙는" 방식은 유지하되, **지표의 책임자**는 유닛마다 명확히.
- PO=미니CEO 감각: 유닛별로 "이번 주 지표를 움직일 한 가지"만 정해서 실행.
