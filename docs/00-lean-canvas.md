## 0. 한 줄 정의

> **3050이 전화 걸지 않고도 가격까지 비교할 수 있는, 강남3구 웰니스 업체 지도.**
> *High-level concept: 웰니스계의 강남언니*

**커버 카테고리 (3축)**

| 축 | 포함 업종 |
|---|---|
| `운동·바디` | 필라테스 · 요가 · PT · GX · 체형교정 |
| `릴렉스·회복` | 스파 · 사우나 · 찜질 · 마사지 · **괄사 · 경락 등 동양 전통 케어** |
| `메디컬 웰니스` | 한의원 · 도수치료 · 영양수액 · 검진 |

**지역 시드:** 강남구 · 서초구 · 송파구

---

## 1. Problem

| | 문제 | 확신 |
|---|---|---|
| **P1** | **가격이 공개되지 않는다.** 필라테스·도수·스파 대부분 "전화문의". 비교 자체가 불가능하고, 3050은 시간 비용이 비싸 이 마찰이 특히 크다 | 🟢 |
| **P2** | **후기를 믿을 수 없다.** 네이버 블로그는 체험단이고, 대부분 20대 기준이라 *내 허리 · 내 갱년기 · 내 체력* 맥락이 없다 | 🟢 |
| **P3** | **잘못 고르면 수십~수백만원이 잠긴다.** 장기 회원권 강매 → 3~4번 가고 만다 | 🟡 |

**기존 대안 (= 진짜 경쟁자)**
네이버 지도 + 블로그 · 지인 추천 · 맘카페/직장인 커뮤니티 · 당근
→ *강남언니는 시술만 다뤄 웰니스 영역은 비어 있다.*

## 2. Customer Segments

**얼리어답터 (가설)**
> 강남·서초·송파 거주 또는 근무하는 **38~52세**, 최근 6개월 내 **통증 · 체력저하 · 갱년기 신호**를 겪고 필라테스/도수/마사지를 **새로 찾아본** 사람

- **2차:** 4050 남성 (골프 체형교정 · 사우나 · 도수)
- **비대상 (명시적 제외):** 업체 오너 — MVP에서 공급 사이드는 고객이 아님

## 3. Unique Value Proposition

> ### "전화 안 걸고 가격까지 비교하는, 3050 웰니스 지도"

**대체 불가 포인트:** *회당 단가로 환산된 가격* × *3050 몸 상태 기준 필터*

## 4. Solution

|---|---|---|---|
| **S1** | **회당 단가 정규화** — "10회 65만" / "20회 110만" / "3개월 무제한 45만"을 비교 가능한 단일 축으로 환산 | P1 | ✅ 핵심 |
| **S2** | **3050 니즈 태그 필터** — 허리·목 / 갱년기 / 운동초보 / 여성전용 / 1:1 / 주차 / 샤워실 / 평일오전 | P2 | ✅ |

## 5. Channels 🟢

**1채널은 SEO.** 이것이 기술 스택 결정의 근거다.

- 롱테일 조합 페이지 대량 생성: `지역 × 카테고리 × 니즈`
  예) `강남 필라테스 가격` · `서초 도수치료 후기` · `송파 여성전용 사우나` · `역삼 허리 필라테스`
- 에디터 실사 콘텐츠 = 크롤링 데이터로는 못 만드는 **유니크 콘텐츠** → 랭킹 무기 겸 신뢰 앵커 (이중 역할)
- 보조: 네이버 검색, 맘카페 / 블라인드, 인스타 릴스

## 6. Revenue Streams 🔴

> **MVP 단계 매출 = 0 (의도적).** 리드 단가가 증명되기 전에는 과금 모델을 확정하지 않는다.

**화폐 대용 지표:** `Qualified Lead` 발생량

**미래 옵션 (우선순위, 리드 검증 후 재평가)**
1. 체험·원데이권 커머스 마진 (소비자 가치와 가장 정렬)
2. 업체 프로필 구독 / 상단 노출
3. 리드 건당 과금

**구조적 주의:** 강남언니는 *1회성 고가* 구매라 리드 단가가 비싸 성립한다. 웰니스는 *반복 구독형*이고 동네 업체 월 마케팅 예산이 30~100만원 수준이라 **리드 판매 모델을 그대로 복사하면 단가가 안 나온다.** 이것이 수익화를 뒤로 미룬 이유다.

## 7. Key Metrics

**North Star** — `업체 상세 → 연락/예약 액션 수 (Qualified Lead)`

**선행 게이트 지표**

| 지표 | 목표 | 의미 |
|---|---|---|
| **가격 커버리지율** | ≥ 40% | 강남3구 수집 업체 중 회당가 산출 가능 비율. **이게 안 되면 UVP가 붕괴** |
| 검색 → 상세 CTR | ≥ 15% | 채널 가설 |
| 니즈태그 필터 사용률 | ≥ 25% | S2가 진짜 차별점인지 |
| 4주 재방문율 | ≥ 20% | 일회성 검색 도구 이상인지 |

## 8. Unfair Advantage

**초기엔 없다 (정직하게).** 시간이 지나며 축적되는 것:

- **3050 니즈 태그 체계** — 업종별 용어를 통증·생애주기 언어로 번역한 온톨로지
- **정규화된 가격 DB** — 크롤링은 복제 가능하지만 *정제 규칙*은 축적물
- **에디터 실사 리포트** — 복제하려면 똑같이 발로 뛰어야 함

# 🔴 Riskiest Assumptions — Discovery 순서

> **코드 작성 전에 이 둘부터 돌린다. 서로 독립이므로 병렬.**

### RA-1. 가격 데이터를 애초에 모을 수 있는가 *(최우선)*
UVP 전체가 여기에 매달려 있다.

- **검증:** 강남3구 표본 100개 업체(3축 카테고리 균등 배분)를 수동/반자동 조사 → 공개 채널에서 가격이 확인되는 비율 측정
- **게이트:**
  - `≥ 40%` → 원안대로 진행
  - `25~40%` → 진행하되 에디터 실사로 가격 보강, 커버리지를 카테고리별로 차등
  - `< 25%` → **UVP 피봇** (가격 → 다른 축)

### RA-2. SEO로 실제 트래픽이 잡히는가
채널 가설 전체가 여기에 매달려 있다.

- **검증:** 타깃 롱테일 키워드 검색량 + SERP 경쟁 강도 분석 (구글 / 네이버 분리 측정), 신규 도메인 진입 가능성 판단
- **게이트:** 상위 10위 진입 현실적인 롱테일 키워드가 충분히 확보되는가

### RA-3. 3050이 새 서비스를 방문할 이유가 있는가 *(후순위)*
RA-1·RA-2 통과 후 실제 트래픽으로 관측.

## 열린 이슈

- [ ] 에디터 실사는 스케일되지 않음 → **전량 커버가 아니라 카테고리×지역 대표 20~30곳의 신뢰 앵커**로 역할 한정. 나머지는 크롤링 데이터로 커버
- [ ] 업체 미접촉 방침이어도 정보 오류·삭제 요청 대응 창구는 필요 → S5로 최소 반영
- [ ] 메디컬 웰니스(한의원·도수)는 **의료광고법 규제 대상** → 가격·후기 표기 방식에 별도 가드레일 필요 (별도 태스크)
