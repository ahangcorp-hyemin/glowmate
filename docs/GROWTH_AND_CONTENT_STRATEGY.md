# GlowMate 성장·콘텐츠 전략 — "병원 가기 전에 여는 앱"

> 리서치 종합(2026-08). 정보기반 + 존나 쉬운 UX로 유저를 모은 국내외 기업 플레이북을
> 뜯어, GlowMate의 4050 포지셔닝과 시술 콘텐츠 증강 스펙으로 합침.

---

## 0. 포지셔닝 한 줄

**"시술 받을까 고민될 때, 병원 가기 전에 여는 앱."**
시술 하나하나에 대해 *결정에 필요한 모든 것*(효과·리스크·정직한 가격대·병원 고르는 법·
상담 때 물어볼 질문)을 쉽게 정리해서, 4050이 병원에서 안 당하고 잘 결정하게 돕는다.

경쟁(강남언니·바비톡·여신티켓)은 20~30대 + 후기/이벤트/견적 중심이고, 유인·알선(§27③)
리스크를 안고 booking 수수료로 수익을 낸다. GlowMate는 **정보 신뢰 + 4050 + 무수수료 정렬**로
차별화한다.

## 1. 관통하는 승리 공식 (모든 사례 공통)

1. **판매자가 숨기는 객관적 데이터를 무료로 → 신뢰 확보 → 나중에 인접 수익화.**
   호갱노노(국토부 실거래가), 화해(성분·EWG), 뱅크샐러드(마이데이터 자산조회),
   GoodRx(약국별 현금가), RealSelf(환자 실제 가격·후기)가 전부 이 구조.
2. **복잡한 의사결정을 '한눈에 보는 신호 하나'로 압축.**
   RealSelf "Worth It %"(예: 지방흡입 88%), GoodRx의 단일 최저가, The Points Guy의
   포인트 가치(¢/point). GlowMate엔 시술별 **정직한 가격대 밴드 + 만족/할만한가 신호**가 필요.
3. **1화면 1액션, 큰 글씨, 능동형.** 토스가 40~50대까지 마찰 없이 송금하게 만든 핵심.
4. **신뢰를 페이지에 눈에 보이게.** "전문의 검수 / 출처 / 최종 업데이트일" 상시 노출
   (Healthline "Medically reviewed by", NerdWallet 방법론 공개). GlowMate의 룰베이스
   *출처 인용* 답변과 정확히 같은 방향.
5. **유저에게 과금하지 말고 상대편(병원·광고주)에게 과금.** 아래 §3.

## 3. §27③ 안전한 수익 정렬 (반드시 지킬 3원칙)

1. **결정은 공짜, 상대편에게 과금.** RealSelf·GoodRx·Zocdoc 패턴 = 투명 정보 무료 +
   병원 정액 광고/노출료. **예약·건당 수수료 금지**(강남언니 유죄가 증명한 천장).
2. **Pay-to-rank 금지.** The Points Guy의 실패지점(수수료 높은 게 'best'로 둔갑)을 피한다.
   정렬 기준은 항상 유저 이득(가격 낮은 순·근거)이고, '광고'는 명확히 배지 표기.
3. **무료 정보를 인질로 잡지 마라.** 똑닥 교훈. 핵심 결정 정보는 계속 무료. 과금은
   인접 프리미엄(심화 리포트·예약 편의)에서, 그것도 형평성 논란 안 나게.

## 4. 시술별 "가기 전 결정 콘텐츠" 증강 스펙 (핵심 산출물)

의료 공유의사결정(SDM/IPDAS) 6요소 + 시술 상담 가이드(ASPS·AAD)에서 도출.
각 시술 페이지가 아래 A~I를 담는다. **이게 곧 DB 스키마의 새 필드가 된다.**

**A. 이게 뭐고 나한테 맞나** — 한줄 정의·작용원리(어느 피부층), 적응증, 좋은 후보 조건, 기대 난이도(극적 vs 유지형)
**B. 대안 비교** — 경쟁 시술 비교표(작용층·효과·유지·통증·가격 나란히), 조합 시너지 vs 낭비, **"안 하기" 옵션**(SDM 필수)
**C. 효과(과대광고 경계)** — 효과 시점(즉시 vs 재생 2~3개월), 유지기간·재시술 주기, **현실적 기대치**("리프팅≠수술급", 개인차)
**D. 회복·통증·과정** — 다운타임(붉은기·붓기·멍 일수), 통증·마취, 소요시간/회차/샷수
**E. 리스크·부작용·금기** — 흔한 vs 드문/중대(빈도 표기 흔함/드묾/매우드묾), **금기 대상**(임신·수유·특정질환·필러/실/보형물 이력)
**F. 비용 구조(숨은 비용 투명화)** — 가격 변동요인(샷·부위·용량·팁수), 병원마다 왜 다른가(저가 미끼 원리), 숨은 비용(마취·재시술·애프터), **적정가 밴드(min–median–max)**
**G. 병원·의사 고르는 법 + Red flags** — 전문의 확인, **정품·식약처 허가 조회법(의약품안전나라 nedrug.mfds.go.kr)**, 상담 체크(시술자=상담의?·전후사진), Red flags(당일결제 압박·극단 저가·100% 보장·원장 안 보임·샷수 불명확)
**H. 상담 질문 리스트** — "제가 이 시술 후보인가요?" "쓰는 장비·제제가 정품·식약처 허가품인가요?" "부작용 대응은?" "총비용에 마취·재시술·애프터 포함?" "몇 샷/몇 cc?" "원장님이 직접?"
**I. 시술 전/후 관리(Do&Don't)** — 전 중단할 것(약·음주), 후 금기(사우나·격한운동·자외선), 이상신호 병원연락 기준

> 현재 `procedures.ts`는 A·C·D·E 일부만 있음. B(대안 비교표), F(가격 구조·밴드),
> G(병원 고르는 법·정품확인), H(상담 질문지), I(전후관리)가 **신규 증강 대상**.

## 5. 대표 성장 자산: "상담 질문지" (콘텐츠 × 바이럴 동시 타격)

- 시술별 **상담 질문 리스트(H)를 한 장 카드**로 만들고 **카톡 공유 / 이미지 저장 / "병원 갈 때 지참"** 버튼.
- 4050의 공유 인프라 = 카톡·지인 단톡방. 유용성이 곧 공유 동기("이건 알고 가야 손해 안 본다" = 손실회피 프레이밍).
- "친구도 병원 가기 전 체크" 초대 루프 → 무료 심화 리포트 언락(가벼운 리퍼럴).

## 6. 4050 UX 규칙

- 본문 최소 16px, 핵심 18~20px+. 고딕·높은 명도대비. 사용자 글씨크기 존중.
- 1화면 1메시지·짧은 문장. **점진적 공개**(요약카드→탭/아코디언으로 심화; 정보량은 많되 첫 화면은 가볍게).
- 큰 터치타깃 체크리스트 + 진행률. 초저마찰 진입.
- 신뢰 신호 상시 노출: 출처 링크(식약처/논문)·전문의 검수·최종 업데이트일·**"의학적 조언 아님, 상담은 의료진과"**(§27 방어 겸용).
