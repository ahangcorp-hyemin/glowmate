# UGC 포맷 리서치 — 4050 후킹용 "뉴 포맷" 설계

> 2026-08. 3갈래 병렬: 캐릭터챗 크리에이터 구조(크랙·C.AI·제타) / 비영상 구조화 UGC 전 카테고리 /
> SoYoung·중국 뷰티 콘텐츠 포맷 진화. 결론 = 영상이 아니라 **"폼+음성+판정"의 결합 포맷**.

---

## 1. 리서치가 준 재료

### 캐릭터챗(크랙·Character.AI·제타)의 이전 가능 역학
- **템플릿이 곧 창작 도구**: 폼 5칸 = 창작. C.AI 봇 1,800만(월 900만 신규), 제타 하루 500캐릭터. 영상 대비 제작 마찰이 자릿수로 낮음.
- **자기용 창작이 먼저**: C.AI는 수년간 보상 0원으로 UGC 폭발(내가 쓸 봇을 만들고 공개는 부산물).
- **콜드스타트**: 오픈 즉시 창작 도구 개방+팬덤 IP(C.AI), 경쟁 플랫폼 인기작 현금 매입(크랙). 크랙 정산: 월 ₩1,000만+ 수십 명, 최고 ₩3,000만 — 돈은 상위층을 프로화, 지위는 나머지를 지탱.
- **1-9-90**: 좋은 크리에이터 수백 명이면 수백만 소비를 지탱.
- **4050**: 캐릭터챗 소비층은 1020 편중(Replika 45세+ ~10%). 단 **음성 소비는 검증**(클로바 케어콜: 시니어 5만, 응답률 96%, 만족 ~90%) → 4050 창작은 체크박스+짧은 필드+**음성 입력**으로 설계해야.

### 저마찰 구조화 UGC 6법칙 (전 카테고리)
① 글쓰기→**폼필링**(쿡패드 재료+단계, 잡플래닛 3칸, 오늘의집 집들이 순서) ② **이미 가진 것을 '공개'로 재정의**(내 집·내 요리·내 연봉·내 견적 — Glassdoor/블라인드/성예사 견적 빅데이터) ③ **판정 코드 표준화**(레딧 AITA의 NTA/YTA — 반응 자체가 초저마찰 UGC) ④ **Give-to-Get**(Glassdoor 1건 제출→12개월 열람) ⑤ **AI가 마감 품질 보장**(스노우 AI 프로필: 소재만 주면 완성, 2개월 매출 ~150억) ⑥ **Before/After 최강 템플릿**.
- 결정적 증거: **만개의레시피** — 이용자 1,000만+, 여성 70~80%·20~50대. **4050 여성은 이미 폼필링 형식으로 매일 창작 중.**
- 4050은 공개 피드보다 **폐쇄형·지인 기반**(밴드·카스)에서 활발 — 소모임 단위 설계가 참여율을 올림.

### 중국 포맷 진화의 교훈
- **AI 얼굴 스캔 = 역사상 최고의 무비용 훅**(SoYoung 魔镜测脸 연 2.7억 회) — 단 "점수·성형 미리보기"는 외모불안 조장 규제(중국 2021 위법화)·의료법 §56과 정면 충돌 → **"기록·추적"으로 재해석**해야(전후 셀프 아카이브).
- **구조화 노트 > 영상**(샤오홍슈): 검색·저장·비교 가능 + 실사용 톤 신뢰. 의미용 규제 대숙청에서 살아남은 것 = 전문의 과학보급·비영리 톤 개인 경험담뿐. 기관 광고·대필·MCN 대리운영은 전 플랫폼에서 숙청.
- **에디토리얼 랭킹**(绿宝石 의사 랭킹: 익명 교차심사+PwC 감사) = 커머스 없이 권위를 만드는 신뢰 자산 — §27③와 양립 가능한 "심사" 포지셔닝.
- 중국 30-50 여성 전환 공식: **전문가 문답 + 소규모 커뮤니티**(위챗 视频号 사구). 오픈 라이브 커머스는 규제로 사망.
- SoYoung 자체 교훈: 포맷 혁신만으로 플랫폼 방어 실패(더우인에 잠식) — 포맷은 훅이고 해자는 데이터·신뢰.

## 2. 제안: "뉴 포맷" = 견적 노트 × 음성 수다 × 판정 (하나의 루프)

영상 UGC가 아니라, **4050이 이미 잘하는 두 가지 — 숫자 공개와 수다 — 를 폼과 AI로 콘텐츠화**한다.

### 포맷 A. 견적 노트 (데이터 기부형 · 최우선)
- 창작 = 드롭다운+숫자 입력(시술명/병원 유형/지역/견적가/실결제가/포함 항목/한 줄 소감). **글쓰기 제로.**
- AI가 깔끔한 공유 카드로 마감(스노우 패턴) → 밴드·카톡 공유 최적화.
- **Give-to-Get**: 내 견적 1건 기부 → 우리 동네 시세 전체 열람.
- 이것이 동시에: UGC 포맷 + **적정가 밴드 실데이터 해자** + §56 안전(치료경험담이 아니라 가격·사실 정보) + 손실회피 바이럴("바가지 방지").

### 포맷 B. 말로 남기는 후기 (음성 구술 → AI 구조화 노트)
- 4050이 3분 말하면(수다·라디오 사연 정서) AI가 구조화 노트(계기/과정/비용/회복/한줄평) 초안 작성, 유저는 승인·수정만. **박막례의 '손녀' 역할을 AI가 수행.**
- 근거: 50대 47% 음성 도구 사용, "말하기는 이미 가진 기술". 국내 뷰티 플랫폼 중 음성 UGC 전무 = 차별화 그 자체. (팀의 음성 DNA와도 일치)
- 노트에 음성 클립 일부를 남기면 "진짜 사람" 신뢰 신호(대필 방지 효과 겸용).

### 포맷 C. 판정 참여 (소비자를 원탭 창작자로)
- 견적 노트에 표준 판정 코드: **"적정 / 비쌈 / 더 알아보세요"** (AITA 구조). 성형 커뮤니티의 "이 견적 어때요?" 관습을 제품화.
- 소비만 하던 유저가 원탭으로 참여 → 판정 집계 자체가 콘텐츠("이 견적, 78%가 '비쌈'").

### 루프
```
견적 노트 기부(A) ──→ 시세 열람 언락(Give-to-Get)
      │                        │
      ▼                        ▼
판정 참여(C) ←── 피드 탐색(의도 없는 브라우징) ──→ 레슨·견적·병원 CTA
      │
      ▼
시술 후 → 말로 남기는 후기(B) → 시술 수첩(여정)과 연결
```

### 보조 레이어 (신뢰·전환)
- **의사 실명 문답**(더우인 교훈: 본인 발화 과학보급만 규제 내구성) — 주 1회 Q&A 포맷.
- **폐쇄형 소모임**: "울쎄라 알아보는 사람들" 단톡형 소그룹 — 4050의 밴드 정서.
- **AI 스캔 훅은 "기록"으로**: 점수 없이 피부·전후 셀프 아카이브(시술 수첩의 사진 타임라인과 동일 기능).

## 3. 콜드스타트 (캐릭터챗 플레이북 적용)

1. 팀 시딩: H1 인터뷰(동의 시) 자체가 첫 "말로 남기는 후기" 콘텐츠 — 인터뷰 15~20건 = 초기 노트 15~20개.
2. 견적 노트는 공개 비급여 고시·커뮤니티 공개 데이터로 "시세 카드" 선제작(큐레이션) → 유저 기부분이 쌓이면 교체.
3. 상위 기여자 소액 보상은 **현금·건당 금지**(SoYoung 가짜 다이어리의 직접 원인) — 열람권·배지·시세 리포트 언락으로.

## 4. 품 (바이브코딩 관점)

| 조각 | 품 |
|---|---|
| 견적 노트 폼+카드 생성+시세 열람 게이트 | 2~3일 ✅ |
| 판정 투표+집계 | 1일 ✅ |
| 음성 구술→구조화(브라우저 STT+템플릿 추출+§56 필터) | 2~3일 ✅ |
| 피드(노트+판정+CTA 세로 스크롤) | 1~2일 ✅ |
| 의사 문답·소모임 | 운영 확보 후 |

## 5. 리스크 가드레일

- 대필·조작: 건당 현금 보상 금지, 음성 클립=사람 증명, 영수증 인증 배지, 병원발 업로드 금지(SoYoung 3대 실패 원인 전부 회피).
- §56: 노트 필드에 효과 보증·과장 표현이 못 들어가게 폼 자체가 제약(자유 텍스트 최소화) + bannedPhrases 필터.
- §27③: 노트→병원 연결은 정액 광고 배지 병원만, 커미션 없음. 판정·시세는 광고와 분리.
- 외모불안 프레임 금지: 점수·등급·시뮬 없음. "기록·시세·판별"만.
