# 몰입형 "피부 속 세계" 정보 포맷 — 근거·제작·파일럿 설계

> 2026-08. Chloe vs History 착안: "찍을 수 없는 세계(피부 속)로 AI 안내원이 들어가 시술 원리를 체험시키는" 몰입 정보 포맷.
> 판정: **근거 강함(포맷·오디언스·이해·신뢰 4중 입증) + 미용시술에서 미결합 = 공백. 주간 제작 현실적. 병목은 비용 아니라 일관성 체리픽.**
> 자매: `AI_INFO_PERSONA_CASES.md`, `AI_PERSONA_RESEARCH.md`.

## 1. 왜 이게 해자인가 (핵심 통찰)

Chloe의 진짜 무기 = AI 은폐가 아니라 **"찍을 수 없는 세계를 만들어 안내자가 1인칭 POV로 그 안에 들어가 반응·참여"**. 강의를 "가이드와 함께 그곳에 있는 경험"으로 전환. 우리 도메인의 등가물 = **4050이 가장 보고 싶지만 절대 볼 수 없는 곳 = 피부 속(표피→진피→SMAS)**. 모든 시술의 "왜"는 찍을 수 없는 장소에서 시간에 걸쳐 일어나는 이야기 → 생성형 영상만 만들 수 있는 세계.

## 2. 근거 (4중 입증)

**포맷 (Chloe)**: 5개월 합산 100만+ 구독, 티타닉 릴스 430만뷰. 엔진 = Utopai PAI(캐릭터 일관성). 반응 요인 = **몰입+친근함**(AI 신기함 아님). [Utopai PAI Pro](https://www.utopaistudios.com/pai-pro)

**오디언스 (몸속 시각화가 대중을 모은다)**:
- **Nucleus Medical Media** 6M+ 구독·20억뷰 — 환자·일반인 대상 인체 메커니즘 애니 수요 입증. [채널](https://www.youtube.com/channel/UC85VW73bQLEjs_taFKP7TwQ)
- **Kurzgesagt** 25M 구독(면역학→서사 여행→베스트셀러). **Osmosis** 2M. **Inner Life of the Cell(Harvard/XVIVO)** — 이해도 ~30% 측정 향상 + 과학 권위. [XVIVO](https://xvivo.com/examples/the-inner-life-of-the-cell/)
- 문화적 프레임 = Fantastic Voyage/매직 스쿨버스 "몸속 여행" 이미 익숙.

**이해·신뢰 (설득 메커니즘)**:
- 메타분석(21편): 애니메이션은 건강 학습 향상, **효과가 학생보다 환자군에서 더 큼**(4050 딱).
- RCT: 시술·합병증 이해도 **+ 치료 신뢰도**를 글보다 높임.
- **Narrative transportation**: 이야기 몰입 → **반론(counterarguing) 감소** = 공포담 선노출 4050의 회의감을 낮춤.
- 시니어도 잘 만든 애니 건강영상에 잘 반응(2026 JMIR Aging: gen-AI 건강영상이 정적 콘텐츠보다 시니어 참여 우위).

**공백 확인**: 울쎄라·써마지 메커니즘 콘텐츠는 병원·장비사의 **다이어그램+보이스오버**뿐. 표피→SMAS를 **안내자와 1인칭 여행**하는 몰입 포맷은 미용시술에 부재. Chloe 몰입 + Nucleus 메커니즘의 **미결합 지점 = 화이트스페이스.**

## 3. 반드시 지킬 것 (반면교사)

- **FDA 제재 사례**: 미용장비 광고를 "암시적 이미지로 효능 과장"·"미확립 기전 주장"으로 제재. → **"콜라겐이 되살아난다"식 드라마 = 효능 암시 = §56/§27③ 위반 위험.**
- 규칙: **"어디서 무슨 일이 일어나나(원리·해부)"는 O, "그래서 예뻐진다(효능·결과)"는 X.** 메커니즘은 임상 정확, 결과 암시 배제.
- Chloe 팩트체크 논란 = 의료 브랜드엔 그대로 교훈. **해부학 정확성 = 생명선**(자문의 감수 필수).

## 4. 제작 스택 (3인·주간 1편)

**추천 = 이미지 앵커 img2vid 하이브리드**
1. **캐릭터 고정**: Higgsfield **Soul ID**(사진 20+장 학습 → 여러 영상모델에 identity 이식) 또는 Nano Banana Pro 레퍼런스. 안내원 1명 = 재사용 정체성. [Soul ID](https://higgsfield.ai/blog/sould-id-best-character-consistency)
2. **애니메이트**: **Kling 3.x**(한국어 립싱크·다샷 강점) 또는 **Veo 3.1**(리얼리즘·미세/의학 디테일) 샷별 라우팅.
3. **한국어 나레이션**: **Supertone**(한국어 TTS 품질 1위·따뜻함) 또는 Typecast(가성비). **온카메라 립싱크 대신 월드 위 보이스오버**(안내원은 제스처, 카메라에 말 안 함)가 주간 제작엔 가장 안전.
4. **조립**: CapCut/Premiere 30~60초.
- **대안 단일툴**: **Utopai PAI 2.0**(Chloe의 실제 엔진, ~$100/1만 크레딧) — 파이프라인 통째 대체 가능성, 유료 트라이얼 가치 있음.

**해부 세계 = 하이브리드 (핵심 결정)**
- **AI 생성(Veo/Seedance)**: 몰입 분위기 b-roll, 한계비용 ~0. 단 **해부학을 지어냄**(층·세포 부정확) → 정보/뷰티 톤엔 OK, 의학 주장엔 위험.
- **3D 의학애니(Blender/BioDigital/VOKA)**: 정확·재사용. 단 외주 $15k~80k·10~12주 = 주간 불가.
- **결론: 하이브리드** — 주간은 AI 생성 월드+안내원, **정확성이 중요한 컷용 3D 피부층/세포 에셋을 1회만 소량 제작(or BioDigital 라이선스)**해 드롭인. 비용 상한 + 주장 방어 가능. **주간 맞춤 3D는 금물.**

## 5. 경제성·병목

- **툴 월비용 ~$150~400** (Higgsfield Ultra ~$99 or Kling Pro+Veo 종량 + Supertone/Typecast ~$20~50 + PAI 트라이얼). 1회성: 3D 에셋 라이브러리 ~$5k~20k(or 스톡 라이선스).
- **편당 30~60초 = 숙련 제너럴리스트 2~4일**. 조건부 주간 가능: 안내원 정체성 사전 고정 + 포맷 템플릿 고정 + 해부 에셋 선제작 + 보이스오버. 초반 4~6편은 파이프라인 안정화까지 느림.
- **#1 병목 = 비용 아니라 "과학적으로 그럴듯 + 캐릭터 일관 + 같은 스타일" 샷의 체리픽 반복.** 생성 2~4배 뽑아 골라야. → 완화 = 경직된 반복 템플릿 + 캐릭터 1회 고정.

## 6. 파일럿 설계 — 『울쎄라, 피부 속으로』 (30~45초)

포맷 = 시술 1개 = 세계 1편. 대본 소스 = 룰베이스 카탈로그(§56 통과) + 레슨 layers·timeline 카드.

1. **콜드오픈(3s)**: 안내원 일상 배경 → "울쎄라가 대체 어디서 작동하는지, 직접 들어가 볼게요" [상단 "AI 안내원" 라벨]
2. **하강(8s)**: 표피→진피→SMAS 통과, 층 이름 나레이션(layers 카드의 여정화)
3. **그 순간(8s)**: 4.5mm에서 초음파 열이 한 점으로 모이는 자리 옆에 서서 — "성형수술에서 당기는 바로 그 층이에요"
4. **타임랩스(8s)**: 콜라겐이 수축했다가 서서히 차오르는 경과(timeline 카드의 세계화). ※ "되살아난다" 대신 "여기서 이만큼 탄탄해져요" — 효능 암시 배제
5. **현실화·판별(6s)**: "수술처럼 당기는 건 아니에요. 지방층이 얇은 분은 여기가 이래서 상담이 필요해요"(기대치+C4)
6. **아웃(4s)**: "더 궁금하면 견적·질문지에서" → 앱 CTA. 하단 출처(식약처 허가·논문)
- 배포: **앱 발견 피드 임베드 우선**(검색 신뢰자산·체류) + 유튜브 쇼츠 보조.

## 7. GlowMate 통합

이 포맷은 새 기둥이 아니라 **기존 자산의 몰입 스킨**: layers/timeline 카드 = 2D 정적 원본, 룰베이스 출처 답변 = 대본, AI 안내원(공개·큐레이터) = 가이드. 13개 시술 = 13편 = 앱+유튜브 재사용. 승리 3요소(공개 페르소나·유용 정보·출처 병기, `AI_INFO_PERSONA_CASES.md`)와 완전 정렬 + 남들이 못 베끼는 생성형 세계 = 해자.
