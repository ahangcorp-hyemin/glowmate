# 후기 보상 ROI 계산법 — 기프티콘은 '붓는' 게 아니라 재는 것

> 2026-08-15. 집품·모두닥 분석에서 도출. 결론: 보상형 후기는 이 업계 표준(강남언니·바비톡·모두닥·집품 전부)이며,
> 문제는 "해도 되냐"가 아니라 "재면서 하냐"다.

## 0. 전제 — 순서를 틀리면 진짜로 돈을 붓게 된다

```
❌ 잘못된 순서: 모르는 사람에게 보상 뿌려 후기 수집 (콜드 트래픽 구매 = CAC, 비쌈)
✅ 검증된 순서: 공공데이터 공개 페이지(무료 검색 유입) → 이미 온 방문자에게 보상 (전환비용, 쌈)
```
집품·모두닥 모두 후자. 트래픽은 프로그래매틱 페이지가 만들고, 보상은 **작성 전환의 마지막 한 걸음**만 지불한다.
우리도 공개 페이지(병원 2,791·레슨·Q&A)가 먼저, 보상은 그 트래픽 위에서만.

## 1. 후기 1개 가치 — 두 개의 공식

### 바닥값: 대체비용법 (이 후기가 만드는 유입을 광고로 사면 얼마?)
```
후기 가치(월) ≥ 후기로 늘어난 페이지 유입 세션/월 × 해당 키워드 CPC
```
- 의료·시술 키워드 CPC는 수천 원대(네이버 기준 상위 키워드는 그 이상).
- 예: 후기 붙은 병원 페이지가 **월 +10세션** × CPC 3,000원 = **월 3만원어치 트래픽**
  → 기프티콘 5,000원은 첫 달에 회수. 이후는 전부 흑자.
- 시술 후기는 수명이 김(수년 유효) → 감가 느린 콘텐츠 자산.

### 천장값: 리드환산법 (후기가 전환에 기여하면?)
```
후기 가치 ≤ 후기가 기여한 전화·지도클릭 수 × 병원 리드 시장가(CPL 3~10만원)
```
- 후기 1개가 전화클릭 1건에만 기여해도 원가(5천원)의 6~20배.

### 판정
```
기프티콘 단가 < 바닥값(월)  →  1개월 내 회수, 무조건 진행
바닥값 < 단가 < 천장값      →  리드 기여 측정으로 판단
단가 > 천장값               →  중단
```

## 2. 측정 설계 (가정이 아니라 숫자로)

| 지표 | 정의 | 도구 |
|---|---|---|
| 후기당 유입 증분 | 후기 등록 전/후 해당 병원 페이지 세션 | GA4/Vercel Analytics |
| 후기당 리드 기여 | 후기 있는 페이지의 전화·지도클릭율 vs 없는 페이지 | 이벤트 계측(A/B 자연실험) |
| 작성 전환율 | 후기 CTA 노출 대비 작성 완료 | 퍼널 이벤트 |
| 후기 원가 | 기프티콘 + 검수 인건 시간 | 운영 기록 |

**Kill rule (미리 박아두기)**: 후기당 월 유입 증분 < 기프티콘 단가/CPC(≈2세션) 상태가 2개월 지속되면 보상 중단·단가 조정.

## 3. 우리의 단계별 예산 (0 → 50만원)

| 단계 | 방법 | 비용 | 기대 |
|---|---|---|---|
| 1 | **H1 인터뷰 부산물** — 인터뷰 15~20명(사례비 5만원 기책정) 말미에 후기 1~2개씩 | **+0원** | 후기 20~30개 |
| 2 | 지인 스노우볼 — "비슷한 고민 친구분 소개" 경로에 후기 요청 동봉 | 0원 | +10~20개 |
| 3 | **방문자 전환형** — 공개 페이지 트래픽 발생 후에만 후기 CTA+기프티콘 노출 | 5,000원×100 = 50만원 | 실험 (kill rule 적용) |

## 4. 품질·법 조건 (집품·모두닥 벤치마크)

- **3단계 인증**: 본인인증 + 영수증/홈택스 인증 + 수기 검수 — 마찰은 적이 아니라 해자(4050 불신 세그먼트에 특효).
- **표시광고법**: 대가 지급 사실 표기 의무("기프티콘을 받고 작성한 후기입니다").
- **§56**: 과장·보증 표현 검수(우리 bannedPhrases 필터 재사용). 병원과의 대가 관계 금지(§27 — 보상은 우리가, 병원이 아님).
- 부정 후기 삭제 압력에 응하지 않는 원칙 명문화(신뢰 자산의 핵심).
