# 콘텐츠 생산 플랜 — '알아보기' 필러를 어떻게 채우나

> 2026-08-15. 울쎄라 레슨의 방법론을 표준화. 목적 = SEO 유입 + 병원 모객 증거 + 4050 신뢰.

## 1. 생산 방법론 (울쎄라 방식의 표준화)

```
수요 선정 → 리서치(공식→임상→커뮤니티) → §56 자체검열 → 카드 조립 → 시드 배포 → (전파 후) DB 승급
```

1. **수요 선정**: 4050_DECISION_RESEARCH §8.1 언급 랭킹 순. 울쎄라(80) ✅ → **써마지(37)·실리프팅(37)·보톡스(34)·리쥬란(21)** → 필러(20)·인모드/스킨부스터(18)·토닝·피코.
2. **리서치 소스 우선순위**: ① 식약처/FDA 허가정보(기전·적응증) ② 학회·의사회 콘텐츠(임상 합의) ③ 병원 임상 칼럼 교차검증(가격 구조·샷수·유지) ④ 커뮤니티 공포담/오해(리터러시 카드 소재 — 반박 말고 '내 조건 판별'로).
3. **§56 자체검열**: 카피에 보증·최상급·완치·부작용없음 금지(bannedPhrases 기준). 효과는 "개인차" 전제. 유지기간은 흡수기간과 분리.
4. **카드 조립 규칙** (types.ts union):
   - 필수: intro → layers/기전 → timeline(기대 현실화) → compare(대안) → contra(내 조건 판별=C4) → price(미끼 경고) → questionSheet → done
   - reviewLiteracy: 교육용 '나쁜 예' 인용은 허용(명시적 예시 프레임).
   - **realReviews 금지**: 실후기가 수집되기 전까지 넣지 않는다(가짜 '검증' 후기 = 우리 원칙 위반). 탐색 필러(P0-5)로 수집되면 그때 DB에서 join.
5. **배포**: 정적 시드(seed.ts) → `/learn/[id]` 자동 노출(허브가 lessonIds로 렌더) → `bun run seed`로 DB 승급.
