# 가격 데이터 수집·노출 전략 (콜드스타트) — 이슈 #67 C11

## 문제
우리는 병원 제출 가격이 0건이다(모두닥과 구조적 차이). HIRA 비급여에도 미용 시술 가격이 사실상 없다.
지금 보여줄 수 있는 건 카탈로그의 **추정 범위**뿐인데, "실제 가격"을 어떻게 수집하고 언제부터 노출할 것인가.

## 수집 (지금부터)
1. **후기가 가격 수집기다.** ReviewForm에 실결제 총액(만원)·예상범위 비교(in_range/higher/lower/unsure)·시술 스펙을 받는다(전부 선택 입력 — 필수로 만들면 제출률이 죽는다).
2. 비교 기준은 병원 제출가가 아니라 **우리 견적 범위**다. "글로우메이트에서 본 예상 범위와 비교해 어땠나요?" — 병원 데이터 없이도 지금 당장 작동한다.
3. 파트너 병원이 생기면: 병원 확인가를 별도 테이블로 받고 '병원 확인' 배지로 구분(이번 스코프 아님).

## 노출 (임계값 규칙)
- **시술별 실결제 후기(paid_amount 있는 승인 리뷰) < 3건**: 어디에도 "실제 가격" 미노출. 카탈로그 추정 범위만.
  - 이유: 1~2건은 표본이 아니라 일화다. 틀린 가격을 보여주는 순간 신뢰 자산이 죽는다(우리 포지셔닝의 전부).
- **≥ 3건**: 레슨·견적 결과에 "실결제 후기 N건: X만~Y만원" 블록 자동 노출(min/max, 이상치 그대로 — 가공하지 않고 건수 명시).
- **≥ 10건**: 중앙값 표기 추가 검토.
- 병원 단위 노출은 병원×시술 3건부터(동일 규칙).

## 부트스트랩 (0→3건을 어떻게)
- 유저 인터뷰 참여자에게 후기 작성 요청(USER_INTERVIEW_KIT 연계) — 사례비와 별개로 부탁(대가성 리뷰 아님, reward_disclosed 플래그 기존 존재).
- 커뮤니티 배포 시 "내가 낸 가격 남기기 = 또래 돕기" 프레이밍(홈 액션 카드).
- 목표: 4주 내 울쎄라·보톡스 각 3건.

## 하지 않는 것
- 가격 blur + 클릭 유도(모두닥) — 데이터가 없으면서 있는 척하는 다크패턴이 됨.
- 소수 표본의 평균 표기 — 범위와 건수만.
