## 1. 미모먼트 플로우 (관찰)

| 기능 | 관찰 내용 |
|---|---|
| 역경매 견적 | 시술 담기(장바구니) → 요청 폼(자유입력·선호지역 필수·예산 필수) → "23시간 남음 · 받은 견적 N · 병원이 보내면 카카오 알림톡" |
| 지도 탐색 | 지도 핀(99+) + 검색바 "찾고 있는 병원이 있나요?" + 바텀시트 카드(평점·가격/대기/만족/접근/언어 아이콘) + **비파트너 병원도 노출**("파트너를 맺지 않은 병원이에요" 라벨) |
| 병원 상세 | 파트너 배지·사진·주소 복사·전화·영업시간·소개·의료진·방문자 리뷰·지도. 하단 고정 [♡][병원 상담][방문 예약] |
| 방문 희망 | 날짜·시간 신청 → "병원에서 직접 연락드릴 예정" → 방문 희망 내역 목록 |
| 마이페이지 | 예약 내역·방문 희망 내역·저장한 병원·작성한 리뷰 (가입 기반) |

## 2. 배울 것 / 안 배울 것 (판정)

| 미모먼트 요소 | 판정 | 이유·우리 버전 |
|---|---|---|
| 병원명 검색바 | ✅ **지금** | 우리 2,791 DB로 즉시 가능. 병원찾기 상단에 추가 |
| 저장한 병원(찜) | ✅ **지금** | **가입 없이 localStorage**(우리 원칙: 가입·연락처 최소화). 하트 토글 + '내 활동' |
| 견적 다시보기 | ✅ **지금** | 미모먼트의 '받은 견적함'을 우리식으로: **내 견적 스냅샷 저장**(localStorage)·다시보기 |
| 마이(내 활동) | ✅ 라이트 | 가입 없는 /saved: 저장 병원 + 최근 견적. 후기는 익명이라 목록 미제공(정직 고지) |
| 하단 고정 병원 CTA | ✅ 이미 있음 | 전화·길찾기·홈페이지. + **'전화 전 질문지' 링크**(우리만의 알고가기 차별) |
| 비파트너 병원 노출+라벨 | ✅ 이미 우리 방식 | 우리는 전체가 공공데이터 — 향후 입점 병원에 '파트너' 배지 다는 역방향 |
| 역경매 견적(병원이 보냄) | ⏸ P2 | 입점 병원 0 + 알림톡 인프라 없음. 입점 후 검토(§27 정액 관계 하에서) |
| 방문 예약/방문 희망 신청 | ❌ 보류 | 예약 중개는 §27 유인·알선 리스크 + 병원 전달 채널 없음. 우리는 전화 직통(수수료 0) 유지 |
| 지도 멀티핀 뷰 | ⏸ 대기 | Kakao JS SDK 키 활성화 필요(현재 REST 403). 키 활성화 후 |
| 사진·의료진·영업시간 | ❌ 못 긁음 | 공공 API 부재(확정 리서치). 입점 병원 제공 필드로 — 빈 값 흉내 금지 |
| 평점 0.0 노출 | ❌ 반면교사 | 데이터 없는 "0.0 (0)"은 신뢰 훼손. 우리는 없는 값은 아예 숨김 |

## 3. 이번 구현 스코프
1. 병원찾기 **이름 검색**(검색 시 거리 대신 전국 이름 매칭)
2. **찜**: 병원 상세·목록 하트 → localStorage → **/saved '내 활동'**(저장 병원 + 최근 견적)
3. **견적 스냅샷 저장**: 견적 완료 시 자동 저장(최근 5개), /saved에서 다시보기
4. 병원 상세에 **"전화 전에 물어볼 질문 보기"** 링크(해당 시술 레슨 questionSheet로)
